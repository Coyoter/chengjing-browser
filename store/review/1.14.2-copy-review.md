最自由的瀏覽器，順暢瀏覽網頁時，還能隨心打造專屬介面！內建「天眼開發者工具」，讓你自由自訂樣式、互動與個人化網站設定。


## Google Play 完整描述

澄境瀏覽器是一款可輕鬆自定義網頁的瀏覽器，與「天眼開發者工具」完美結合。你可以輕鬆查看當前頁面的結構，挑選想調整的元件，加入自訂樣式、互動效果或內容，並儲存為個人專屬設定。請放心，這些調整只會改變你在澄境中的顯示方式，完全不會影響網站伺服器的原始碼。

天眼開發者工具
• 視覺化目前頁面的 DOM 結構，點選元件並向外選取父層。
• 為元件新增 CSS、JavaScript 或 HTML，或編輯其內部 HTML。
• 依個人需要調整頁面元件的呈現與內容。
• 保存網站設定，日後開啟符合網域與結構的頁面時自動套用。
• 暫時顯示原始網站，或復原上一份儲存的設定。

新視窗與導覽，由你設定
可依網站選擇是否啟用「防止跳轉與彈窗」。正常文字、圖片連結與網站轉址仍可使用；需要的新視窗，也能從「攔截紀錄」選擇「在新分頁開啟」，接續原本的操作。

想做什麼嘗試？直接問 AI
可選用本機 Gemma 4 E2B 或 OpenRouter，描述你想讓網站有什麼變化。網站 AI 可協助思考整體版面；元件 AI 則聚焦已選取的部分。查看建議與修改內容後，即可一鍵套用。

AI 使用目前開啟頁面的有限結構及你提供的需求，不代表已檢查整個網站的所有頁面。Gemma 4 E2B 在手機上運行，不需 API Key；須先下載約 2.59 GB 模型，並使用具有足夠空間與記憶體的相容 64 位元裝置。OpenRouter 則需自行提供 API Key，服務可能收費；每次雲端分析前會告知傳送的資料並取得同意。AI 建議可能有誤，請確認適合自己的用途再套用。

把瀏覽整理得更順手
• 分頁管理、頁面搜尋、網址列歷史建議與下拉重新整理。
• 影片全螢幕時隱藏系統列。
• 書籤資料夾、搜尋及網址編輯。
• 匯入 Chrome 匯出的 HTML 書籤，並支援書籤匯出。
• 獨立收藏與閱讀進度，快速接續上次看到的位置。
• 書籤與收藏顯示網站小圖示，方便辨認。
• 選用 Google Drive 書籤與天眼網站設定同步，僅存取本應用的專用隱藏資料空間。
• 淺色、深色、跟隨系統，以及上下網址列配置。

資料與使用範圍
書籤、收藏、瀏覽紀錄與網站設定以本機保存為主。Google 同步與 AI 都是自行選擇的功能。應用內提供資料用途、保存與刪除方式。

澄境使用手機的 Android System WebView 瀏覽網頁，內核更新由裝置的 WebView 提供者負責。部分網站、跨來源內嵌頁面與特殊元件有存取限制；網站結構改版後，既有修改可能需要調整。自訂 JavaScript 具有頁面程式碼的能力，請使用你了解用途的內容。

## 英文完整描述

ChengJing Browser makes webpage customization easy and integrates seamlessly with Sky Eye developer tools. View the current page's structure, choose the elements you want to adjust, add custom styles, interactions or content, and save your personal settings. These adjustments only change how pages appear in ChengJing; they do not change the website's original server-side code.

Your window and navigation settings
Choose whether to enable "Prevent redirects and pop-ups" for each website. Text links, image links and website redirects remain available. Open a window you need from "Block Records" using "Open in New Tab" to continue your original action.

Optional AI assistance
Describe changes for the website, or ask AI to focus on one selected element. Review the proposed changes and apply them with one tap. AI uses a limited structural snapshot of the current page, your saved customization code and your request; it does not inspect every page of the website. Choose on-device Gemma 4 E2B without an API key, or OpenRouter. The local model requires a separate download of about 2.59 GB, a compatible 64-bit device and sufficient storage and memory. OpenRouter requires your own API key and provider fees may apply; consent is requested before each cloud analysis. AI suggestions may be incorrect.

Everyday browsing
Tabs, local address-bar history suggestions, immersive fullscreen video, in-page search, pull to refresh, website icons in bookmarks and reading collections, bookmark folders, editable bookmark URLs, Chrome HTML bookmark import and export, a separate reading collection, optional Google Drive sync for bookmarks and Sky Eye website settings, light and dark themes, and top or bottom address-bar layouts.

Data and compatibility
Most browser data is stored locally. Optional Google sync uses only this app's private Drive app-data space. In-app privacy information explains data use and deletion. The browser uses your device's Android System WebView; engine updates come from its provider. Some sites and embedded elements have compatibility or access restrictions. Saved customizations may need adjustment when a site changes. Custom JavaScript has webpage-code capabilities; use code you understand.

The app interface supports 17 languages.
