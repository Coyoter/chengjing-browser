澄境瀏覽器，讓日常瀏覽與網頁探索，在同一個地方完成。

打開網站，也能打開它的結構。內建「天眼開發者工具」，用可視化邊框查看網頁元件，點選想調整的部分，加入樣式、互動或自己的內容。修改只套用在你自己的瀏覽器中，不會變更網站伺服器上的原始碼。

天眼開發者工具
• 視覺化目前頁面的 DOM 結構，點選元件並向外選取父層。
• 為元件新增 CSS、JavaScript 或 HTML，或編輯其內部 HTML。
• 自行選擇要保留或移除的頁面元件。
• 保存網站設定，日後開啟符合網域與結構的頁面時自動套用。
• 暫時顯示原始網站，或復原上一份儲存的設定。

想做什麼嘗試？直接問 AI
可選用本機 Gemma 4 E2B 或 OpenRouter，描述你想讓網站有什麼變化。網站 AI 可協助思考整體版面；元件 AI 則聚焦已選取的部分。查看建議與修改內容後，即可一鍵套用。

AI 使用目前開啟頁面的有限結構及你提供的需求，不代表已檢查整個網站的所有頁面。Gemma 4 E2B 在手機上運行，不需 API Key；須先下載約 2.59 GB 模型，並使用具有足夠空間與記憶體的相容 64 位元裝置。OpenRouter 則需自行提供 API Key，服務可能收費；每次雲端分析前會告知傳送的資料並取得同意。AI 建議可能有誤，請確認適合自己的用途再套用。

把瀏覽整理得更順手
• 分頁管理、頁面搜尋、網址列歷史建議與下拉重新整理。
• 影片全螢幕時隱藏系統列。
• 書籤資料夾、搜尋及網址編輯。
• 匯入 Chrome 匯出的 HTML 書籤，並支援書籤匯出。
• 獨立收藏與閱讀進度，快速接續上次看到的位置。
• 書籤與收藏顯示網站小圖示，方便辨認。
• 選用 Google Drive 書籤與天眼網站設定同步，僅存取本應用的專用隱藏資料空間。
• 淺色、深色、跟隨系統，以及上下網址列配置。

資料與使用範圍
書籤、收藏、瀏覽紀錄與網站設定以本機保存為主。Google 同步與 AI 都是自行選擇的功能。應用內提供資料用途、保存與刪除方式。

澄境使用手機的 Android System WebView 瀏覽網頁，內核更新由裝置的 WebView 提供者負責。部分網站、跨來源內嵌頁面與特殊元件有存取限制；網站結構改版後，既有修改可能需要調整。自訂 JavaScript 具有頁面程式碼的能力，請使用你了解用途的內容。
