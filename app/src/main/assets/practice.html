慢一點，看清楚

把網頁調成習慣的樣子。

這是手機裡的練習網頁。你可以調整元件，也能加入自己的樣式與頁面內容。

點工具列的「天眼」，開啟後點選元件。若只選到文字，按「選取外面一層」，直到框住整塊元件，再預覽移除。

網頁的主角，應該是你想看的內容。

新增一點自己的東西

打開天眼，選「新增 CSS」就能調整樣式。例如讓段落更寬鬆：

main { line-height: 2; }

選「新增 JS」，可以在頁面加入閱讀提醒：

if (!document.getElementById("my-note")) {
  const note = document.createElement("p");
  note.id = "my-note";
  note.textContent = "記得休息一下";
  document.querySelector("main").prepend(note);
}

移除之後呢？

儲存規則，再前往第二頁。雖然元件內容不同，只要結構相同，它依然不會打擾你。
