Slow down, look carefully

Adjust the webpage to your preferred style.

This is a practice webpage on your phone. You can adjust components and add your own styles and content.

Tap 'SkyEye' on the toolbar, then select a component. If only text is selected, tap 'Select Outer Layer' until the entire component is framed, then preview removal.

The main focus of a webpage should be the content you want to see.

Add a bit of your own touch

Open SkyEye, select 'Add CSS' to adjust styles. For example, make paragraphs more spacious:

main { line-height: 2; }

Select 'Add JS' to add reading reminders to the page:

if (!document.getElementById("my-note")) {
  const note = document.createElement("p");
  note.id = "my-note";
  note.textContent = "Remember to take a break";
  document.querySelector("main").prepend(note);
}

What happens after removal?

Save the rule, then go to the second page. Even if component content differs, as long as the structure is the same, it won’t bother you.
