Data yang Disimpan di Ponsel
Bookmark, favorit dan kemajuan bacaan, riwayat penelusuran, kata kunci pencarian di bilah alamat, tab yang dibuka, mesin pencari default dan template URL pencarian kustom, aturan situs web, CSS/JS/HTML kustom, tampilan dan pengecualian sertifikat situs disimpan di ponsel. Situs web mungkin menyimpan cookie, cache, dan data penyimpanan situs melalui WebView. Saran bilah alamat dicocokkan dengan kata kunci pencarian dan riwayat lokal, tanpa mengirim teks yang sedang diketik ke layanan saran; hanya setelah Anda mengirim pencarian, teks pencarian akan dikirim ke layanan pencarian yang dipilih. Bookmark dan favorit menyimpan ikon situs yang diperoleh saat browsing; jika tidak ada ikon, mungkin langsung meminta ikon dari /favicon.ico situs tersebut, tanpa menggunakan proxy ikon pihak ketiga atau mengirim jalur bookmark lengkap atau parameter URL. Data ini tidak otomatis dikirim ke server pengembang hanya karena aplikasi diinstal. Aplikasi ini tidak memiliki sistem akun sendiri, juga tidak memiliki layanan statistik penggunaan atau pelaporan kesalahan bawaan.

Sinkronisasi Bookmark Google, Favorit, dan Pengaturan SkyEye (opsional)
Hanya setelah Anda menghubungkan Google, aplikasi akan menggunakan izin drive.appdata untuk membaca dan menulis ruang data tersembunyi Google Drive khusus aplikasi ini; tidak membaca dokumen Drive lain Anda. Data sinkronisasi mencakup nama bookmark, URL, folder, catatan modifikasi dan penghapusan, serta ID perangkat sinkronisasi yang dibuat aplikasi. Favorit menyinkronkan ID, nama kustom, URL bacaan saat ini, judul halaman, posisi gulir, persentase bacaan, waktu modifikasi, dan status penghapusan. ID akun Google dan email digunakan untuk mengidentifikasi akun sinkronisasi. Jika "Sinkronkan Pengaturan Situs SkyEye" diaktifkan, domain, aturan komponen, CSS/JS/HTML kustom, pengaturan perilaku situs, serta status modifikasi dan penghapusan juga disinkronkan; kode mungkin berisi konten pribadi, harap verifikasi terlebih dahulu. Riwayat penelusuran, kata kunci bilah alamat, pilihan mesin pencari dan template kustom, pengecualian sementara, pengecualian sertifikat, dan kunci OpenRouter tidak disertakan dalam sinkronisasi. Sinkronisasi dapat terjadi otomatis saat aplikasi dibuka atau data sinkronisasi diubah. Favorit yang sama menggunakan catatan penyimpanan lengkap terbaru; tidak memaksa menggunakan persentase bacaan tertinggi atau berpindah otomatis ke halaman yang sedang dibuka. Versi aplikasi lama tidak menyinkronkan favorit, harap perbarui semua perangkat yang perlu sinkronisasi ke versi yang didukung.

Penggunaan Data Google terbatas pada fungsi sinkronisasi yang Anda minta, mematuhi Kebijakan Data Pengguna Layanan API Google, termasuk persyaratan Penggunaan Terbatas; data akun Google atau sinkronisasi cloud tidak diberikan ke penyedia AI untuk pelatihan model. Layanan Google memproses data sesuai kebijakan privasinya: https://policies.google.com/privacy

Bantuan AI (opsional)
Anda dapat memilih untuk tidak menggunakan AI, atau memilih model lokal Gemma 4 E2B atau OpenRouter.

Model Lokal Gemma 4
Model sekitar 2,59 GB akan diunduh dari repositori model komunitas LiteRT di Hugging Face melalui layanan unduhan Android hanya setelah Anda menekan unduh; sumber unduhan menerima alamat IP dan permintaan unduhan, diproses sesuai kebijakan privasi mereka: https://huggingface.co/privacy. Model disimpan di ponsel setelah verifikasi integritas, analisis dijalankan di perangkat, tanpa mengirim pertanyaan, struktur halaman, atau kode kustom ke layanan AI cloud. Fungsi lokal tidak memerlukan API Key; Anda dapat menghapus model yang diunduh di pengaturan AI. Memerlukan perangkat 64-bit kompatibel dengan ruang penyimpanan dan memori cukup.

Model Cloud OpenRouter
Setelah memasukkan OpenRouter API Key, kunci disimpan dan dilindungi oleh Android Keystore di ponsel. Data hanya dikirim ke OpenRouter dan penyedia model yang dipilih setelah Anda menyetujui pengiriman data dan menekan analisis, termasuk domain saat ini, struktur komponen terbatas, CSS/JS/HTML kustom yang disimpan, aturan komponen, dan pertanyaan yang Anda masukkan, untuk memeriksa aturan SkyEye. Analisis SkyEye biasa hanya menggunakan struktur terbatas; dalam "Revisi Aturan AI", setelah persetujuan Anda, juga mengirimkan HTML asli terbatas yang diambil sebelum penerapan SkyEye dan konten pengeditan saat ini. HTML mengecualikan konten kontrol formulir, area yang dapat diedit, skrip, atribut event, dan parameter query dalam atribut URL, namun mungkin berisi teks halaman pribadi; snapshot ini hanya disimpan di memori halaman, tidak ditulis ke disk. Aplikasi tidak membaca nilai formulir atau cookie; namun pertanyaan, penamaan komponen, aturan, dan kode kustom mungkin berisi data pribadi yang Anda atau situs masukkan; HTML yang diedit juga dapat mengandung teks asli komponen, harap verifikasi konten terlebih dahulu. API Key digunakan untuk otentikasi ke OpenRouter, tidak diberikan ke halaman web. Aplikasi menetapkan data_collection=deny ke OpenRouter, mengecualikan jalur penyedia model yang mengizinkan pengumpulan data. Rekaman akun, biaya, dan pengolahan data lain OpenRouter tetap sesuai kebijakan dan pengaturan akun mereka. Kebijakan: https://openrouter.ai/privacy

Browsing Situs dan Pemeriksaan Versi
Saat membuka halaman web, situs dan sumber yang dimuat menerima permintaan jaringan, alamat IP, identifikasi browser, dan cookie yang berlaku. Saat Anda mengirim teks pencarian dari bilah alamat, teks dikodekan URL dan dikirim ke layanan pencarian Google, Bing, Yahoo, Baidu, Naver, Wikipedia bahasa Mandarin, atau HTTPS kustom yang Anda pilih; hasil pencarian, wilayah yang tersedia, dan pengolahan data diatur oleh kebijakan layanan tersebut. Pemeriksaan versi Chromium terbaru menghubungkan ke layanan versi Google; pembaruan daftar model AI manual menghubungkan ke OpenRouter. File HTTP/HTTPS dikelola oleh layanan unduhan Android; file blob/data yang dihasilkan halaman web ditulis secara bertahap secara lokal ke Downloads/ChengJing oleh aplikasi, tidak diunggah ke server aplikasi. Unduhan ini memerlukan halaman sumber tetap tersedia, pembatalan atau gangguan akan membersihkan output yang belum selesai. File unduhan dan catatan disimpan di ponsel, tidak dihapus oleh tab penyamaran; file cache baru tidak menyimpan URL sumber penyamaran. Tekan lama gambar tetap memverifikasi dan menyimpan gambar, impor dan ekspor bookmark hanya menggunakan file yang Anda pilih melalui sistem.

Koneksi dan Kode Kustom
Sinkronisasi Google dan koneksi asli OpenRouter menggunakan verifikasi sertifikat HTTPS. Browsing web memverifikasi sertifikat secara default; Anda dapat secara manual mengizinkan pengecualian permanen untuk nama host HTTPS tertentu dari ikon koneksi di bilah alamat (termasuk port berbeda, tidak termasuk subdomain lain). Pengecualian disimpan sampai Anda menutup aplikasi, mengurangi jaminan otentikasi situs, dan bilah alamat akan menampilkan peringatan. Situs HTTP tidak terenkripsi. JavaScript yang Anda tambahkan memiliki kemampuan kode halaman tersebut, dapat membaca konten halaman atau mengirim permintaan, gunakan hanya kode yang Anda pahami tujuannya.

Penyimpanan, Penghentian, dan Penghapusan
Data lokal dikelola oleh masing-masing fungsi. Riwayat penelusuran menyimpan hingga 250 halaman terbaru, kata kunci pencarian hingga 100 entri; cache ikon situs menyimpan hingga 30 hari, 256 entri, dan 8 MiB; cache halaman dikelola oleh mekanisme kapasitas WebView. Anda dapat menghapus riwayat di riwayat penelusuran, menghapus item di bookmark atau favorit, menghapus pengaturan di aturan domain, menghapus API Key di pengaturan AI, atau menonaktifkan pengecualian sertifikat situs dari ikon koneksi. Untuk mencegah perangkat offline menambahkan kembali favorit yang dihapus, catatan sinkronisasi dengan status penghapusan dan bidang asli disimpan; tidak lagi ditampilkan di daftar favorit. Untuk menghapus semua data lokal (termasuk cookie situs, penyimpanan, dan catatan penghapusan sinkronisasi), gunakan Android "Pengaturan → Aplikasi → ChengJing Browser → Penyimpanan → Hapus Data" atau copot pemasangan; ini akan mereset aplikasi, harap ekspor bookmark yang diperlukan terlebih dahulu.

"Berhenti Sinkronisasi dan Logout" hanya menghentikan sinkronisasi aplikasi ini, menyimpan bookmark, favorit, kemajuan bacaan, dan pengaturan situs di lokal dan Google Drive. Untuk menghapus data cloud, hentikan sinkronisasi di semua perangkat terlebih dahulu, lalu hapus data aplikasi tersembunyi "ChengJing Browser" di Google Drive versi web melalui "Pengaturan → Kelola Aplikasi"; Anda juga dapat mencabut akses di halaman koneksi pihak ketiga akun Google. Menghubungkan kembali perangkat dengan data dapat mengunggah ulang data lokal yang dipilih untuk sinkronisasi. Data yang dikirim ke OpenRouter atau penyedia model harus ditangani atau diminta penghapusannya sesuai layanan tersebut. Pengembang tidak dapat langsung membaca atau menghapus data ponsel, Google Drive, atau akun OpenRouter pribadi Anda.

Perubahan Kebijakan dan Kontak
Jika penggunaan data berubah, penjelasan ini akan diperbarui; fitur yang memerlukan izin tambahan akan meminta persetujuan terpisah. Jika ada pertanyaan tentang pengolahan data atau cara penghapusan, kirim email ke admin@techtarian.com; jangan berikan kata sandi atau API Key.

Mesin Pencari Default (1.9.0)
Pengaturan → Browsing memungkinkan memilih Google, Bing, Yahoo, Baidu, Naver, Wikipedia bahasa Mandarin, atau menyediakan template URL pencarian HTTPS dengan satu {query}. Google adalah default. Pilihan dan template kustom disimpan di ponsel, tidak disinkronkan dengan Google; menghapus data aplikasi atau uninstall akan menghapusnya juga. Bilah alamat terlebih dahulu menentukan URL jelas atau teks pencarian secara lokal, teks yang sedang diketik tidak dikirim ke layanan saran online. Hanya saat pencarian dikirim, teks pencarian dikirim ke layanan yang dipilih. Mode penyamaran menggunakan pengaturan yang sama, tetapi tidak menambahkan kata kunci pencarian ke riwayat lokal. Layanan kustom dipilih oleh Anda, harap pastikan URL dan kebijakan privasinya.

Tab Penyamar dan Daftar Unduhan (1.4.0)
Tab penyamaran menggunakan profil WebView berbeda dari tab biasa, tidak berbagi cookie, cache, dan penyimpanan situs. Tidak menambahkan riwayat browsing atau pencarian lokal, tidak menyimpan URL tab untuk pemulihan ulang, dan tidak menghasilkan thumbnail pratinjau tab. Menutup semua tab penyamaran akan meminta pembersihan cookie, cache jaringan, dan penyimpanan situs profil ini; pembersihan adalah tugas asinkron. Jika proses berhenti tidak normal, saat berikutnya dibuka akan membersihkan profil penyamaran lama dan tidak menggunakan sesi tersebut lagi. Ini tidak menjamin anonimitas sempurna terhadap sistem operasi atau forensik fisik, juga tidak menyembunyikan aktivitas Anda dari situs, pemberi kerja, atau penyedia jaringan.
Bookmark, favorit, aturan situs, dan unduhan sistem yang Anda buat secara aktif akan disimpan. Sebelum unduhan penyamaran, akan diingatkan lagi tentang penyimpanan file dan catatan unduhan sistem; tindakan pengiriman aktif seperti berbagi sistem dan analisis AI tetap mengikuti konfirmasi dan kebijakan layanan asli. Android System WebView yang mendukung isolasi dan pembersihan data diperlukan; jika tidak didukung, akan diberi tahu untuk memperbarui, tidak menyamar sebagai tab biasa.
Daftar unduhan hanya menanyakan catatan unduhan sistem yang dibuat aplikasi ini, tidak memindai file aplikasi lain di ponsel; catatan yang dihapus sistem tidak dijamin dapat dipulihkan. Snapshot pratinjau tab biasa mungkin berisi konten halaman yang terlihat saat ini, mulai 1.4.1 disimpan di ruang khusus internal aplikasi, disimpan bersama tab, dihapus saat tab terkait ditutup; membuka kembali aplikasi tidak menghapusnya. Snapshot tidak disinkronkan dengan Google, tidak dimasukkan ke galeri atau Downloads, dan dikecualikan dari cadangan sistem. Tab penyamaran tidak menghasilkan atau menyimpan snapshot. Menghapus semua data aplikasi atau uninstall akan menghapus snapshot lokal ini.

Beranda dan Kutipan Harian
Tombol beranda, URL beranda kustom, status melihat panduan awal, dan tanggal mulai kutipan harian hanya disimpan di ponsel, tidak disinkronkan dengan Google. 89 kutipan teks disediakan offline bersama aplikasi, tanpa permintaan ke layanan mana pun atau pengunggahan catatan bacaan. Klik aktif pada beranda kustom mengirim permintaan browsing biasa ke situs tersebut; tab penyamaran tetap menggunakan data situs terpisah. Menghapus data aplikasi juga mereset pengaturan lokal ini.

Hapus Data Browsing (1.6.0)
Menu fungsi memungkinkan memilih rentang waktu untuk menghapus riwayat browsing/pencarian lokal, atau menutup tab biasa terakhir yang dibuka dalam periode tersebut dan menghapus snapshotnya. Informasi waktu hanya disimpan di ponsel, tidak disinkronkan dengan Google. Data lama tanpa catatan waktu hanya dapat dihapus dengan opsi "tanpa batas waktu". Cookie, cache, dan data situs dipilih terpisah untuk penghapusan total, default tidak dicentang, dan tidak dibatasi oleh rentang waktu yang dipilih; ini dapat menyebabkan logout situs. Tindakan ini mempertahankan bookmark, favorit, file unduhan, pengaturan SkyEye, dan sesi penyamaran; data penyamaran tetap dihapus dengan menutup tab penyamaran.

Buka Aplikasi Lain (1.7.0)
Klik aktif tautan aplikasi eksternal di halaman web, atau URL umum yang sudah ditetapkan Android untuk aplikasi tertentu, ChengJing akan menyerahkan tautan ke aplikasi terkait. Aplikasi tersebut mungkin menyimpan tautan dan catatan penggunaan sesuai kebijakan mereka; ChengJing tidak menyediakan cookie browsing, riwayat, atau API Key. Mode penyamaran akan memberi peringatan sebelum keluar karena aplikasi lain tidak dikontrol pembersihan penyamaran oleh ChengJing. ChengJing hanya memeriksa penangan tautan HTTP/HTTPS, tidak menyimpan atau mengunggah daftar aplikasi terpasang. Jika aplikasi terkait tidak terpasang dan tautan memiliki fallback halaman web valid, akan dibuka di tab asli.

Operasi Gambar (1.8.0)
Tekan lama gambar untuk pratinjau, salin, unduh, bagikan, atau buka di tab baru. Permintaan pengambilan gambar menggunakan cookie dan identifikasi browser tab tersebut; gambar disimpan sementara secara lokal, maksimal 32 MiB per gambar, cache biasa maksimal 128 MiB, penyamaran maksimal 64 MiB, file lebih dari 24 jam dihapus saat startup dan penulisan. Menghapus cookie, cache, dan data situs juga menghapus cache gambar biasa. Sistem mungkin mengosongkan cache lebih awal; file yang diunduh ke Downloads menjadi tanggung jawab Anda untuk disimpan atau dihapus. Catatan unduhan gambar baru maksimal 500 entri, tidak disinkronkan dengan Google. Salin dan bagikan menggunakan izin baca sementara terbatas pada gambar tersebut untuk menyediakan file asli, aplikasi penerima mungkin menyimpan salinan sesuai kebijakan mereka. Pratinjau penyamaran dihapus saat semua tab penyamaran ditutup; salin, unduh, atau bagikan penyamaran memberi peringatan kemungkinan penyimpanan eksternal. Tab gambar sementara data:/blob: tidak disimpan untuk pemulihan ulang, layar akan mengingatkan untuk mengunduh terlebih dahulu.

Lokasi Situs (1.11.0)
WebView hanya memberikan lokasi ponsel ke situs jika situs meminta lokasi dan Anda mengizinkan situs serta izin lokasi Android. Anda dapat memilih lokasi kasar atau akurat; aplikasi tidak meminta lokasi latar belakang, tidak menyimpan koordinat sendiri, dan tidak mengirim lokasi ke pengembang, sinkronisasi Google, atau layanan AI. Penggunaan lokasi oleh situs diatur oleh kebijakan mereka. Izin lokasi situs biasa hanya disimpan lokal dan dapat diubah di info situs bilah alamat; tidak disinkronkan dengan Google. Izin penyamaran terpisah dari tab biasa, dihapus saat semua tab penyamaran ditutup atau aplikasi keluar. Anda juga dapat mencabut izin lokasi aplikasi di pengaturan Android; menghapus data aplikasi atau uninstall menghapus izin lokal.

Lokasi Langsung Android (1.11.1)
Setelah mendapat izin situs dan Android, ChengJing langsung meminta lokasi dari sumber GPS, jaringan, atau gabungan sistem Android, lalu memberikannya ke situs saat ini. Situs dapat meminta lokasi sekali atau terus-menerus; permintaan dihentikan saat dibatalkan, ganti halaman, tutup tab, atau keluar dari latar depan. Permintaan sekali biasanya menunggu maksimal dua menit, bisa lebih singkat sesuai pengaturan situs. Modul lokasi hanya menggunakan koordinat sementara di memori, tidak merekam atau menyinkronkan. Informasi lokasi yang ditampilkan situs tetap bagian dari konten halaman; pratinjau tab biasa menyimpan tampilan yang terlihat sesuai aturan, tab penyamaran tidak menghasilkan pratinjau. Sistem mungkin menyimpan lokasi terakhir; hanya digunakan dalam batas waktu yang diterima situs. Prinsip izin lokasi situs, isolasi penyamaran, dan tidak menyinkronkan dengan Google/AI tetap sama.
