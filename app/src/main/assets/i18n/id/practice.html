Sesuaikan halaman web sesuai kebiasaan Anda.

Ini adalah halaman latihan di ponsel. Anda dapat menyesuaikan komponen, serta menambahkan gaya dan konten halaman sendiri.

Ketuk 'SkyEye' di toolbar, lalu pilih komponen. Jika hanya memilih teks, tekan 'Pilih Lapisan Luar' sampai seluruh komponen terbingkai, lalu pratinjau penghapusan.

Fokus halaman web seharusnya pada konten yang ingin Anda lihat.

Tambahkan sedikit hal milik Anda sendiri

Buka SkyEye, pilih 'Tambah CSS' untuk mengubah gaya. Misalnya, buat paragraf lebih longgar:

main { line-height: 2; }

Pilih 'Tambah JS' untuk menambahkan pengingat baca di halaman:

if (!document.getElementById("my-note")) {
  const note = document.createElement("p");
  note.id = "my-note";
  note.textContent = "Ingat untuk beristirahat sejenak";
  document.querySelector("main").prepend(note);
}

Setelah dihapus?

Simpan aturan, lalu lanjut ke halaman kedua. Meskipun isi komponen berbeda, selama strukturnya sama, aturan tidak akan mengganggu Anda.

Pergi ke halaman kedua domain yang sama →

Anda juga bisa memilih 'Tampilkan Situs Asli Sementara' dari menu untuk melihat situs asli sementara. Semua aturan tetap ada, tidak perlu pengaturan ulang.
