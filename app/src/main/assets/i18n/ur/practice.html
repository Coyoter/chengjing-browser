ویب پیج کو اپنی عادت کے مطابق ترتیب دیں۔

یہ موبائل میں پریکٹس ویب پیج ہے۔ آپ اجزاء کو ایڈجسٹ کر سکتے ہیں اور اپنی اسٹائلز اور مواد شامل کر سکتے ہیں۔

ٹول بار میں 'SkyEye' پر کلک کریں، پھر اجزاء منتخب کریں۔ اگر صرف متن منتخب ہو تو 'باہر کی ایک تہہ منتخب کریں' دبائیں جب تک کہ پورا جز منتخب نہ ہو، پھر پریویو میں ہٹائیں۔

ویب پیج کا مرکزی کردار وہ مواد ہونا چاہیے جو آپ دیکھنا چاہتے ہیں۔

اپنی کچھ چیزیں شامل کریں

SkyEye کھولیں، 'نیا CSS شامل کریں' منتخب کریں تاکہ اسٹائل ایڈجسٹ کر سکیں۔ مثال کے طور پر پیراگراف کو زیادہ کشادہ بنانے کے لیے:

main { line-height: 2; }

'نیا JS شامل کریں' منتخب کریں تاکہ صفحے پر پڑھنے کی یاد دہانی شامل کی جا سکے:

if (!document.getElementById("my-note")) {
  const note = document.createElement("p");
  note.id = "my-note";
  note.textContent = "ذرا آرام کریں";
  document.querySelector("main").prepend(note);
}
