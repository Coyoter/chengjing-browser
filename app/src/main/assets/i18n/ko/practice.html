웹페이지를 익숙한 모습으로 조정하세요.

이것은 휴대폰 내 연습용 웹페이지입니다. 구성 요소를 조정하거나 자신만의 스타일과 페이지 내용을 추가할 수 있습니다.

도구 모음의 'SkyEye'를 눌러 켠 후 구성 요소를 선택하세요. 텍스트만 선택되면 '바깥쪽 한 겹 선택'을 눌러 전체 구성 요소가 감싸질 때까지 반복한 뒤 미리보기에서 제거하세요.

웹페이지의 주인공은 당신이 보고 싶은 내용이어야 합니다.

자신만의 요소를 조금 추가하세요

SkyEye를 열고 'CSS 추가'를 선택하면 스타일을 조정할 수 있습니다. 예를 들어 문단을 더 여유롭게 만들기:

main { line-height: 2; }

'JS 추가'를 선택하면 페이지에 읽기 알림을 넣을 수 있습니다:

if (!document.getElementById("my-note")) {
  const note = document.createElement("p");
  note.id = "my-note";
  note.textContent = "잠시 휴식하세요";
  document.querySelector("main").prepend(note);
}
