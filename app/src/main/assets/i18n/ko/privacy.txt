휴대폰에 저장된 데이터
북마크, 즐겨찾기 및 읽기 진행 상황, 방문 기록, 주소창 검색어, 열린 탭, 기본 검색 엔진 및 사용자 지정 검색 URL 템플릿, 사이트 규칙, 사용자 지정 CSS/JS/HTML, 외관 및 사이트 인증서 예외가 휴대폰에 저장됩니다. 사이트는 WebView를 통해 쿠키, 캐시 및 사이트 저장 데이터를 저장할 수 있습니다. 주소창 제안은 로컬 검색어 및 방문 기록과 비교하여 이루어지며, 입력 중인 텍스트는 제안 서비스에 전송되지 않습니다; 검색을 제출할 때만 선택한 검색 서비스로 검색어가 전송됩니다. 북마크와 즐겨찾기는 방문 시 획득한 사이트 아이콘을 캐시하며, 아이콘이 없으면 해당 사이트의 /favicon.ico에서 직접 아이콘을 요청할 수 있으며, 제3자 아이콘 프록시는 사용하지 않고 전체 북마크 경로나 URL 매개변수를 전송하지 않습니다. 이 데이터는 앱 설치만으로 개발자 서버에 자동 전송되지 않습니다. 앱에는 자체 계정 시스템이나 내장된 사용 행동 통계 또는 오류 보고 서비스가 없습니다.

Google 북마크, 즐겨찾기 및 SkyEye 설정 동기화(선택 사항)
Google 계정을 연결한 경우에만 앱이 drive.appdata 권한을 사용하여 이 앱 전용 Google Drive 숨김 데이터 공간을 읽고 씁니다; 다른 Drive 문서는 읽지 않습니다. 동기화 데이터에는 북마크 이름, URL, 폴더, 수정 및 삭제 기록, 앱에서 생성한 동기화 장치 식별자가 포함됩니다. 즐겨찾기는 식별자, 사용자 지정 이름, 현재 읽는 URL, 페이지 제목, 스크롤 위치, 읽기 비율, 수정 시간 및 삭제 상태를 동기화합니다. Google 계정 식별자 및 이메일은 동기화 계정을 식별하는 데 사용됩니다. "SkyEye 사이트 설정 동기화"를 활성화하면 도메인, 구성 요소 규칙, 사용자 지정 CSS/JS/HTML, 사이트 동작 설정 및 수정과 삭제 상태도 동기화됩니다; 코드에 개인 정보가 포함될 수 있으니 사전에 확인하세요. 방문 기록, 주소창 검색어, 검색 엔진 선택 및 사용자 지정 템플릿, 임시 예외, 인증서 예외 및 OpenRouter 키는 동기화에 포함되지 않습니다. 앱 실행 및 선택한 동기화 데이터 변경 시 자동 동기화가 발생할 수 있습니다. 동일 즐겨찾기는 최신 완전 저장 기록을 우선하며, 최고 읽기 비율을 강제 적용하거나 현재 보고 있는 페이지로 강제 이동하지 않습니다. 이전 버전 앱은 즐겨찾기를 동기화하지 않으므로 동기화가 필요한 모든 기기에서 지원 버전으로 업데이트하세요.

Google 데이터 사용은 요청한 동기화 기능에 한정되며 Google API Services User Data Policy를 준수하며 Limited Use 요구사항을 포함합니다; Google 계정 또는 클라우드 동기화 데이터를 AI 공급자에게 모델 훈련용으로 제공하지 않습니다. Google이 제공하는 서비스는 해당 개인정보처리방침에 따라 데이터를 처리합니다: https://policies.google.com/privacy

AI 지원(선택 사항)
AI를 사용하지 않거나 로컬 Gemma 4 E2B 또는 OpenRouter를 선택할 수 있습니다.

Gemma 4 로컬 모델
다운로드 버튼을 누른 경우에만 Android 다운로드 서비스를 통해 Hugging Face의 LiteRT 커뮤니티 모델 저장소에서 약 2.59GB 모델을 다운로드합니다; 다운로드 출처는 IP 주소 및 다운로드 요청을 수신하며 해당 개인정보처리방침에 따릅니다: https://huggingface.co/privacy . 모델은 무결성 검증 후 휴대폰에 저장되며, 분석은 기기 내에서 실행되어 문제, 웹 구조 또는 사용자 지정 코드를 AI 클라우드 서비스로 전송하지 않습니다. 로컬 기능은 API 키가 필요 없으며 AI 설정에서 다운로드한 모델을 삭제할 수 있습니다. 64비트 호환 기기와 충분한 저장 공간 및 메모리가 필요합니다.

OpenRouter 클라우드 모델
OpenRouter API 키를 입력하면 키는 Android Keystore로 보호되어 휴대폰에 저장됩니다. 사용자가 데이터 전송에 동의하고 분석 버튼을 누를 때만 현재 도메인, 제한된 구성 요소 구조, 저장된 사용자 지정 CSS/JS/HTML 및 구성 요소 규칙, 입력한 질문이 OpenRouter 및 선택한 모델 공급자에게 전송되어 SkyEye 규칙 검사를 위해 사용됩니다. 일반 SkyEye 분석은 제한된 구조만 사용하며, "AI 규칙 수정"에서 사용자의 이번 동의 후 현재 문서 로드, SkyEye 적용 전 캡처된 제한된 원본 HTML 및 현재 편집 내용을 전송합니다. HTML은 폼 제어 내용, 편집 가능 영역, 스크립트, 이벤트 속성 및 URL 속성 내 쿼리 매개변수를 제외하지만 개인 페이지 텍스트가 포함될 수 있습니다; 이 스냅샷은 페이지 메모리에만 보관되며 디스크에 기록되지 않습니다. 앱은 폼 값이나 쿠키를 읽지 않지만 질문, 구성 요소 명명, 규칙 및 사용자 지정 코드는 사용자 또는 사이트가 입력한 개인 정보를 포함할 수 있으며, 편집된 HTML도 구성 요소 원래 텍스트를 포함할 수 있으니 내용을 확인하세요. API 키는 OpenRouter 인증용이며 웹페이지에 제공되지 않습니다. 앱은 OpenRouter에 data_collection=deny를 지정하여 데이터 수집을 허용하는 모델 공급 경로를 제외합니다. OpenRouter 자체 계정 기록, 비용 및 기타 데이터 처리는 해당 정책 및 계정 설정에 따릅니다. 정책: https://openrouter.ai/privacy

웹사이트 방문 및 버전 조회
웹페이지를 열 때 해당 사이트 및 로드된 출처는 네트워크 요청, IP 주소, 브라우저 식별자 및 적용 가능한 쿠키를 받습니다. 주소창에서 검색어를 제출하면 URL 인코딩되어 선택한 Google, Bing, Yahoo, Baidu, Naver, 중국어 위키피디아 또는 사용자 지정 HTTPS 검색 서비스로 전송되며, 검색 결과, 사용 가능 지역 및 데이터 처리는 해당 서비스 정책에 따릅니다. 최신 Chromium 버전 조회는 Google 버전 서비스에 연결하며, AI 모델 목록 수동 업데이트는 OpenRouter에 연결합니다. HTTP/HTTPS 파일은 Android 다운로드 서비스가 처리하며, 웹페이지에서 생성된 blob/data 파일은 앱이 로컬에서 분할하여 Downloads/ChengJing에 저장하며 앱 서버로 업로드하지 않습니다. 이러한 다운로드는 출처 탭이 유지되어야 하며, 취소 또는 중단 시 미완료 출력이 정리됩니다. 다운로드 파일 및 기록은 휴대폰에 보관되며 시크릿 탭 삭제 시 제거되지 않고, 새 임시 파일 다운로드는 시크릿 출처 URL을 저장하지 않습니다. 이미지 길게 누르기는 이미지 확인 후 저장하며, 북마크 가져오기 및 내보내기는 시스템에서 선택한 파일만 사용합니다.

연결 및 사용자 지정 코드
Google 동기화 및 OpenRouter 네이티브 연결은 HTTPS 인증서 검증을 사용합니다. 웹 브라우징은 기본적으로 인증서를 검증하며, 주소창 연결 아이콘에서 특정 HTTPS 호스트 이름(다른 포트 포함, 하위 도메인 제외)에 대해 영구 예외를 수동으로 허용할 수 있습니다. 예외는 앱 종료 시까지 유지되며 사이트 신원 검증 보안이 낮아지고 주소창에 경고가 표시됩니다. HTTP 사이트는 자체적으로 암호화하지 않습니다. 추가한 JavaScript는 해당 웹페이지 코드 권한을 가지며 페이지 내용을 읽거나 요청을 보낼 수 있으니 용도를 이해하는 코드만 사용하세요.

저장, 중지 및 삭제
로컬 데이터는 각 기능별로 관리됩니다. 방문 기록은 최근 250개 페이지까지, 검색어는 최대 100개까지 보관하며, 사이트 아이콘 캐시는 최대 30일, 256개 및 8MiB까지 저장됩니다. 웹페이지 캐시는 WebView 용량 관리에 따릅니다. 방문 기록에서 기록을 삭제하거나, 북마크 및 즐겨찾기에서 항목을 삭제하거나, 도메인 규칙에서 설정을 삭제하거나, AI 설정에서 API 키를 제거하거나, 연결 아이콘에서 사이트 인증서 예외를 해제할 수 있습니다. 오프라인 기기에서 삭제된 즐겨찾기가 다시 추가되는 것을 방지하기 위해 삭제 후 원본 필드 및 삭제 상태가 포함된 동기화 기록을 보관하며, 즐겨찾기 목록에는 더 이상 표시되지 않습니다. 모든 로컬 데이터를 제거하려면(사이트 쿠키, 저장 및 동기화 삭제 기록 포함) Android 설정 → 앱 → ChengJing Browser → 저장 공간 → 데이터 삭제를 사용하거나 앱을 제거하세요; 앱이 초기화되므로 필요한 북마크는 미리 내보내세요.

"동기화 중지 및 로그아웃"은 앱 동기화만 중지하며 로컬 및 Google Drive의 북마크, 즐겨찾기, 읽기 진행 및 사이트 설정은 유지합니다. 클라우드 데이터를 삭제하려면 모든 기기에서 동기화를 중지한 후 Google Drive 웹에서 설정 → 앱 관리 → ChengJing Browser에서 숨겨진 앱 데이터를 삭제하거나 Google 계정의 타사 연결 페이지에서 접근 권한을 철회하세요. 다시 연결된 기기는 선택한 동기화 로컬 데이터를 다시 업로드할 수 있습니다. OpenRouter 또는 모델 공급자에 전송된 데이터는 해당 서비스 제공 방식에 따라 처리하거나 삭제 요청을 해야 하며, 개발자는 휴대폰, Google Drive 또는 개인 OpenRouter 계정 데이터를 직접 읽거나 대리 삭제할 수 없습니다.

정책 변경 및 연락처
데이터 사용이 변경되면 본 설명서를 업데이트하며, 추가 권한이 필요한 기능은 별도 동의를 구합니다. 데이터 처리 문제나 삭제 방법이 불명확할 경우 admin@techtarian.com으로 문의하세요; 비밀번호나 API 키는 제공하지 마세요.

기본 검색 엔진(1.9.0)
설정 → 브라우징에서 Google, Bing, Yahoo, Baidu, Naver, 중국어 위키피디아 또는 {query}를 포함하는 HTTPS 검색 URL 템플릿을 직접 제공할 수 있습니다. Google이 기본값입니다. 선택 및 사용자 지정 템플릿은 휴대폰에 저장되며 Google 동기화에 포함되지 않습니다; 앱 데이터 삭제 또는 제거 시 함께 삭제됩니다. 주소창은 먼저 로컬에서 명확한 URL과 검색어를 판단하며, 입력 중인 내용은 온라인 제안 서비스에 전달되지 않습니다. 검색 제출 시에만 검색어가 선택한 서비스로 전송됩니다. 시크릿 모드도 동일한 설정을 사용하지만 검색어를 로컬 방문 기록에 추가하지 않습니다. 사용자 지정 서비스는 사용자가 선택하며 URL 및 개인정보처리방침을 확인하세요.

시크릿 탭 및 다운로드 목록(1.4.0)
시크릿 탭은 일반 탭과 다른 WebView 프로필을 사용하며 쿠키, 캐시 및 사이트 저장을 공유하지 않습니다. 로컬 방문 또는 검색 기록에 추가하지 않고, 탭 URL을 저장하거나 복원하지 않으며 탭 미리보기 썸네일도 생성하지 않습니다. 모든 시크릿 탭을 닫으면 해당 프로필의 쿠키, 네트워크 캐시 및 사이트 저장을 비동기적으로 정리합니다. 프로세스가 비정상 종료되면 다음 실행 시 이전 시크릿 프로필을 정리하고 해당 세션을 더 이상 사용하지 않습니다. 이는 운영체제나 물리적 포렌식에 완전한 시크릿을 보장하지 않으며 사이트, 고용주 또는 네트워크 공급자에 대한 활동을 숨기지 않습니다.
사용자가 생성한 북마크, 즐겨찾기, 사이트 규칙 및 시스템 다운로드는 유지됩니다. 시크릿 다운로드 전에 파일 및 시스템 다운로드 기록 보존을 다시 알리며, 시스템 공유, AI 분석 등 적극적인 외부 전송 행위는 기존 확인 및 서비스 정책에 따릅니다. Android System WebView의 데이터 격리 및 정리를 지원해야 하며, 미지원 시 업데이트 알림을 표시하고 일반 탭을 시크릿으로 가장하지 않습니다.
다운로드 목록은 이 앱이 생성한 시스템 다운로드 기록만 조회하며, 휴대폰 내 다른 앱 파일은 스캔하지 않습니다; 시스템에서 제거된 기록은 복구를 보장하지 않습니다. 일반 탭 미리보기 스냅샷은 현재 페이지의 가시 콘텐츠를 포함할 수 있으며, 1.4.1부터 앱 내부 전용 공간에 저장되어 탭과 함께 유지되고 해당 탭 종료 시 삭제됩니다; 앱 재시작 시 삭제되지 않습니다. 스냅샷은 Google 동기화에 포함되지 않고, 앨범이나 Downloads에 저장되지 않으며 시스템 백업에서 제외됩니다. 시크릿 탭은 스냅샷을 생성하거나 저장하지 않습니다. 앱 전체 데이터 삭제 또는 제거 시 이 로컬 스냅샷도 삭제됩니다.

홈 및 오늘의 문장
홈 버튼 토글, 사용자 지정 홈 URL, 초기 설명 확인 여부 및 오늘의 문장 시작 날짜는 휴대폰에만 저장되며 Google 동기화에 포함되지 않습니다. 89개의 문장은 앱 오프라인으로 제공되며, 어떤 서비스에도 조회하거나 읽기 기록을 업로드하지 않습니다. 사용자 지정 홈을 클릭하면 해당 사이트에 일반 브라우징 요청을 보내며, 시크릿 탭은 독립적인 사이트 데이터를 사용합니다. 앱 데이터 삭제 시 이 로컬 설정도 초기화됩니다.

브라우징 데이터 삭제(1.6.0)
기능 메뉴에서 기간을 선택하여 로컬 방문/검색 기록을 삭제하거나 해당 기간 마지막에 방문한 일반 탭을 닫고 스냅샷을 삭제할 수 있습니다. 시간 정보는 휴대폰에만 저장되며 Google 동기화에 포함되지 않습니다. 이전 버전에서 시간 기록이 없는 데이터는 "기간 제한 없음" 삭제 시에만 삭제됩니다. 쿠키, 캐시 및 사이트 데이터는 별도 선택하여 모두 삭제할 수 있으며 기본적으로 선택되어 있지 않고 선택한 기간 제한을 받지 않습니다; 이로 인해 사이트 로그아웃이 발생할 수 있습니다. 이 작업은 북마크, 즐겨찾기, 다운로드 파일, SkyEye 설정 및 시크릿 세션을 유지하며, 시크릿 데이터는 시크릿 탭 종료 방식으로 삭제됩니다.

다른 앱 열기(1.7.0)
웹페이지 내에서 외부 앱 링크를 클릭하거나 Android가 지정한 앱 처리 일반 URL을 ChengJing이 해당 앱에 전달합니다. 상대 앱은 정책에 따라 링크 및 사용 기록을 저장할 수 있으며, ChengJing은 브라우징 쿠키, 기록 또는 API 키를 제공하지 않습니다. 시크릿 모드 종료 전 알림이 표시되며, 상대 앱은 ChengJing의 시크릿 정리 제어를 받지 않습니다. ChengJing은 HTTP/HTTPS 링크 처리기만 조회하며 설치된 앱 목록을 저장하거나 업로드하지 않습니다. 해당 앱이 설치되지 않았고 링크에 유효한 웹 백업이 포함된 경우 원래 탭에서 해당 URL을 엽니다.

이미지 조작(1.8.0)
이미지를 길게 눌러 미리보기, 복사, 다운로드, 공유 또는 새 탭에서 열 수 있습니다. 이미지 요청은 해당 탭의 쿠키 및 브라우저 식별자를 사용하며, 이미지는 로컬에 임시 저장됩니다. 단일 이미지는 최대 32MiB, 일반 캐시는 최대 128MiB, 시크릿 캐시는 최대 64MiB이며, 시작 및 쓰기 시 24시간 초과 파일을 삭제합니다. 쿠키, 캐시 및 사이트 데이터 삭제 시 일반 이미지 캐시도 삭제됩니다. 시스템이 더 일찍 캐시를 회수할 수 있으며, Downloads로 다운로드된 파일은 사용자가 보관하거나 삭제합니다. 새 이미지 다운로드 기록은 최대 500개이며 Google 동기화에 포함되지 않습니다. 복사 및 공유는 해당 이미지에 한정된 임시 읽기 권한을 통해 실제 파일을 제공하며, 수신 앱은 자체 정책에 따라 복사본을 보관할 수 있습니다. 시크릿 미리보기는 모든 시크릿 탭 종료 시 삭제되며, 시크릿 복사, 다운로드 또는 공유 시 외부에 보관될 수 있음을 사전 알립니다. data:/blob: 임시 이미지 탭은 재열기 복원을 위해 저장하지 않으며, 화면에 먼저 다운로드하라는 안내가 표시됩니다.

사이트 위치 정보(1.11.0)
사이트가 위치 정보를 요청하고 사용자가 해당 사이트 및 Android 위치 권한을 허용한 경우에만 WebView가 휴대폰 위치를 사이트에 제공합니다. 대략적 또는 정확한 위치를 선택할 수 있으며, 앱은 백그라운드 위치를 요구하지 않고 좌표를 자체 저장하지 않으며 위치를 개발자, Google 동기화 또는 AI 서비스에 전송하지 않습니다. 사이트의 위치 사용은 해당 정책에 따릅니다. 일반 사이트 위치 권한은 로컬에만 저장되며 주소창 사이트 정보에서 변경할 수 있고 Google 동기화에 포함되지 않습니다. 시크릿 권한은 일반 탭과 분리되어 모든 시크릿 탭 종료 또는 앱 종료 시 삭제됩니다. Android 설정에서 앱 위치 권한을 철회할 수 있으며, 앱 데이터 삭제 또는 제거 시 로컬 권한이 제거됩니다.

Android 직접 위치(1.11.1)
사이트 및 Android 권한이 허용된 후 ChengJing은 Android의 GPS, 네트워크 또는 시스템 융합 위치 소스에서 직접 위치를 요청하여 현재 사이트에 제공합니다. 사이트는 단일 또는 지속 위치 요청이 가능하며, 취소, 페이지 전환, 탭 종료 및 포그라운드 종료 시 관련 요청을 중지합니다. 일반 단일 요청은 최대 2분 대기하며 사이트 설정에 따라 더 짧을 수 있습니다. 위치 모듈은 메모리 내 좌표만 잠시 사용하며 별도 기록이나 동기화를 하지 않습니다. 사이트에 표시되는 위치 정보는 웹 콘텐츠이며, 일반 탭 미리보기는 기존 규칙에 따라 가시 화면을 유지하고 시크릿 탭은 미리보기를 생성하지 않습니다. 시스템은 최근 위치를 저장할 수 있으며, 사이트가 명확히 허용한 기간 내에서만 사용합니다. 사이트 위치 권한, 시크릿 격리 및 Google/AI 동기화 미포함 원칙은 동일하게 유지됩니다.
