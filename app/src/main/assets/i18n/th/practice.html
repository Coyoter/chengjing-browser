ChengJing・สนามฝึก SkyEyeเว็บสาธิตในเครื่อง
แบนเนอร์ข้อมูลทั่วไป · คุณสามารถเลือกเก็บไว้
ช้าลงหน่อย มองให้ชัด

ปรับเว็บให้เป็นแบบที่คุณคุ้นเคย

นี่คือเว็บฝึกในมือถือ คุณสามารถปรับแต่งส่วนประกอบ และเพิ่มสไตล์หรือเนื้อหาของคุณเองได้

แตะที่แถบเครื่องมือ ‘SkyEye’ เปิดแล้วเลือกส่วนประกอบ หากเลือกได้แค่ข้อความ ให้กด ‘เลือกชั้นนอก’ จนกรอบครอบคลุมส่วนประกอบทั้งหมด จากนั้นดูตัวอย่างและลบออก

ตัวเอกของเว็บควรเป็นเนื้อหาที่คุณอยากดู

เพิ่มสิ่งของของคุณเองสักหน่อย

เปิด SkyEye เลือก ‘เพิ่ม CSS’ เพื่อปรับสไตล์ เช่น ทำให้ย่อหน้ากว้างขึ้น:

main { line-height: 2; }

เลือก ‘เพิ่ม JS’ เพื่อเพิ่มการแจ้งเตือนการอ่านในหน้าเว็บ:

if (!document.getElementById("my-note")) {
  const note = document.createElement("p");
  note.id = "my-note";
  note.textContent = "อย่าลืมหยุดพักบ้าง";
  document.querySelector("main").prepend(note);
}

ลบออกแล้วจะเป็นอย่างไร?

บันทึกกฎ แล้วไปหน้าที่สอง แม้เนื้อหาส่วนประกอบจะต่างกัน หากโครงสร้างเหมือนกัน ก็จะไม่รบกวนคุณ
