اضبط الصفحة لتناسب عاداتك.

هذه صفحة تدريب على الهاتف. يمكنك تعديل المكونات وإضافة أنماطك ومحتوى صفحتك الخاص.

انقر على "SkyEye" في شريط الأدوات، ثم اختر مكونًا. إذا اخترت نصًا فقط، اضغط "اختر الطبقة الخارجية" حتى تحيط الإطار بالمكون بالكامل، ثم عاين الإزالة.

البطل في الصفحة هو المحتوى الذي تريد مشاهدته.

أضف شيئًا خاصًا بك

افتح SkyEye، واختر "إضافة CSS" لتعديل الأنماط. مثلاً لجعل الفقرات أكثر اتساعًا:

main { line-height: 2; }

اختر "إضافة JS" لإضافة تذكير بالقراءة في الصفحة:

if (!document.getElementById("my-note")) {
  const note = document.createElement("p");
  note.id = "my-note";
  note.textContent = "تذكر أن تأخذ استراحة";
  document.querySelector("main").prepend(note);
}

ماذا بعد الإزالة؟

احفظ القواعد، ثم انتقل إلى الصفحة الثانية. رغم اختلاف محتوى المكونات، طالما الهيكل نفسه، فلن يزعجك.
