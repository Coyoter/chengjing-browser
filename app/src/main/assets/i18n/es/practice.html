Ajusta la página web a tu estilo habitual.

Esta es una página de práctica en el móvil. Puedes ajustar componentes y añadir tus propios estilos y contenido.

Pulsa 'SkyEye' en la barra de herramientas, luego selecciona un componente. Si solo seleccionas texto, pulsa 'Seleccionar capa exterior' hasta que el marco abarque todo el componente, luego previsualiza y elimina.

El protagonista de la página web debe ser el contenido que quieres ver.

Añade algo propio

Abre SkyEye, selecciona 'Añadir CSS' para ajustar estilos. Por ejemplo, para espaciar más los párrafos:

main { line-height: 2; }

Selecciona 'Añadir JS' para incluir recordatorios de lectura en la página:

if (!document.getElementById("my-note")) {
  const note = document.createElement("p");
  note.id = "my-note";
  note.textContent = "Recuerda tomar un descanso";
  document.querySelector("main").prepend(note);
}

¿Y después de eliminar?

Guarda la regla y ve a la segunda página. Aunque el contenido del componente cambie, si la estructura es igual, no te molestará.
