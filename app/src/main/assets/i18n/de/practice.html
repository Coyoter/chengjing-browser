Passe die Webseite an deine Gewohnheiten an.

Dies ist eine Übungswebseite auf dem Handy. Du kannst Komponenten anpassen und eigene Stile sowie Seiteninhalte hinzufügen.

Tippe in der Werkzeugleiste auf „SkyEye“, wähle dann eine Komponente aus. Wenn nur Text ausgewählt wird, tippe auf „Äußere Ebene wählen“, bis die gesamte Komponente umrahmt ist, dann Vorschau zum Entfernen.

Der Hauptfokus der Webseite sollte der Inhalt sein, den du sehen möchtest.

Füge etwas Eigenes hinzu

Öffne SkyEye, wähle „CSS hinzufügen“, um Stile anzupassen. Zum Beispiel, um Absätze großzügiger zu gestalten:

main { line-height: 2; }

Wähle „JS hinzufügen“, um eine Lesewarnung auf der Seite einzufügen:

if (!document.getElementById("my-note")) {
  const note = document.createElement("p");
  note.id = "my-note";
  note.textContent = "Denk daran, eine Pause zu machen";
  document.querySelector("main").prepend(note);
}

Was passiert nach dem Entfernen?

Speichere die Regel und gehe zur zweiten Seite. Auch wenn der Inhalt der Komponenten anders ist, stört sie dich nicht, solange die Struktur gleich bleibt.

Zur zweiten Seite derselben Domain →

Du kannst auch im Menü „Originalseite vorübergehend anzeigen“ wählen, um die Originalseite kurz zu sehen. Alle Regeln bleiben erhalten, keine Neu-Einstellung nötig.
