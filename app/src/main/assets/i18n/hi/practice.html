सामान्य सूचना बैनर · आप इसे रखने का विकल्प चुन सकते हैं
धीरे करें, ध्यान से देखें

वेबपेज को अपनी आदत के अनुसार सेट करें।

यह मोबाइल में अभ्यास वेबपेज है। आप घटकों को समायोजित कर सकते हैं, साथ ही अपनी शैली और पृष्ठ सामग्री जोड़ सकते हैं।

टूलबार में 'SkyEye' पर टैप करें, फिर घटक चुनें। यदि केवल टेक्स्ट चुना है, तो 'बाहर की एक परत चुनें' दबाएं जब तक कि पूरा घटक चयनित न हो, फिर पूर्वावलोकन में हटाएं।

वेबपेज का मुख्य पात्र वह सामग्री होनी चाहिए जिसे आप देखना चाहते हैं।

अपनी कुछ सामग्री जोड़ें

SkyEye खोलें, 'नया CSS जोड़ें' चुनें ताकि आप शैली समायोजित कर सकें। उदाहरण के लिए पैराग्राफ को अधिक खुला करने के लिए:

main { line-height: 2; }

'नया JS जोड़ें' चुनें, ताकि पृष्ठ पर पढ़ने की याद दिलाने वाला संदेश जोड़ा जा सके:

if (!document.getElementById("my-note")) {
  const note = document.createElement("p");
  note.id = "my-note";
  note.textContent = "थोड़ा आराम करना याद रखें";
  document.querySelector("main").prepend(note);
}

हटाने के बाद क्या?

नियम सहेजें, फिर दूसरे पृष्ठ पर जाएं। भले ही घटक सामग्री अलग हो, यदि संरचना समान है, तो यह आपको परेशान नहीं करेगा।

समान डोमेन के दूसरे पृष्ठ पर जाएं →

आप मेनू में 'अस्थायी रूप से मूल वेबसाइट दिखाएं' भी चुन सकते हैं, ताकि अस्थायी रूप से मूल साइट देख सकें। सभी नियम अभी भी मौजूद हैं, पुनः सेटिंग की आवश्यकता नहीं।

मूल रूप से छिपा हुआ संकेत कंटेनर

यह फ्लोटिंग ब्लॉक पढ़ने की सामग्री को रोक रहा है।

SkyEye का उपयोग करके पूरे हरे क्षेत्र को हटाने का प्रयास करें।
