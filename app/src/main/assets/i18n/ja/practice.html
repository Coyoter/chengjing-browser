ウェブページを慣れた形に調整しましょう。

これはスマホ内の練習用ページです。コンポーネントを調整したり、自分のスタイルや内容を追加できます。

ツールバーの「SkyEye」をタップし、開いたらコンポーネントを選択します。文字だけなら「外側を選択」を押し、コンポーネント全体が囲まれるまで繰り返し、プレビューで削除してください。

ウェブページの主役は、あなたが見たい内容です。

少し自分のものを追加しましょう

SkyEyeを開き、「CSSを追加」を選ぶとスタイルを調整できます。例えば段落を広げるには：

main { line-height: 2; }

「JSを追加」を選ぶと、ページに読書リマインダーを入れられます：

if (!document.getElementById("my-note")) {
  const note = document.createElement("p");
  note.id = "my-note";
  note.textContent = "休憩も忘れずに";
  document.querySelector("main").prepend(note);
}

削除した後は？

ルールを保存して、2ページ目へ。内容は違っても構造が同じなら邪魔されません。
