更新日：2026年9月27日
開発者：Coyoter

端末に保存されるデータ
ブックマーク、お気に入りと読書進捗、閲覧履歴、アドレスバーの検索語、開いているタブ、デフォルト検索エンジンとカスタム検索URLテンプレート、サイトルール、カスタムCSS／JS／HTML、外観とサイト証明書例外は端末に保存されます。サイトはWebViewを通じてCookie、キャッシュ、サイトストレージを保存する場合があります。アドレスバーの候補はローカルの検索語と閲覧履歴を照合し、入力中の文字は候補サービスに送信されません。検索を送信した時のみ、検索語が選択した検索サービスに送信されます。ブックマークとお気に入りは閲覧時に取得したサイトアイコンをキャッシュします。アイコンがない場合は直接サイトの/favicon.icoから取得し、第三者のアイコン代理は使わず、完全なブックマークパスやURLパラメータは送信しません。これらのデータはアプリをインストールしただけで開発者のサーバーに自動送信されません。本アプリは独自のアカウントシステムを持たず、利用行動統計やエラーレポートサービスも内蔵していません。

Googleブックマーク、お気に入りとSkyEye設定の同期（任意）
Googleに連携した場合のみ、drive.appdata権限を使い、このアプリ専用のGoogle Drive非表示データ領域の読み書きを行います。他のDriveファイルは読み取りません。同期データにはブックマーク名、URL、フォルダ、変更・削除履歴、アプリ生成の同期デバイス識別子が含まれます。お気に入りは識別子、カスタム名、現在の閲覧URL、ページタイトル、スクロール位置、読了率、変更時間、削除状態を同期します。Googleアカウント識別子とメールは同期アカウントの識別に使います。「SkyEyeサイト設定の同期」を有効にすると、ドメイン、コンポーネントルール、カスタムCSS／JS／HTML、サイト動作設定、変更・削除状態も同期されます。コードに個人情報が含まれる可能性があるため事前に確認してください。閲覧履歴、アドレスバー検索語、検索エンジン選択とカスタムテンプレート、一時例外、証明書例外、OpenRouterキーは同期に含まれません。アプリ起動時や選択した同期データの変更時に自動同期される場合があります。同じお気に入りは新しい完全な保存記録が優先され、最高読了率の強制採用や閲覧中ページへの強制ジャンプはありません。旧版アプリはお気に入りを同期しないため、同期が必要な端末は対応版に更新してください。

Googleデータの利用は同期機能の要求に限定され、Google API Services User Data Policy（Limited Use要件を含む）に準拠します。Googleアカウントやクラウド同期データをAIプロバイダーにモデル訓練用に提供しません。Googleのサービスはそのプライバシーポリシーに従ってデータを処理します：https://policies.google.com/privacy

AI支援（任意）
AIを使わないことも、本機Gemma 4 E2BまたはOpenRouterを選択することも可能です。

Gemma 4本機モデル
ダウンロードボタンを押した時のみ、Androidダウンロードサービスを通じてHugging FaceのLiteRTコミュニティモデルリポジトリから約2.59GBのモデルを取得します。ダウンロード元はIPアドレスとダウンロード要求を受け取り、プライバシーポリシーに従います：https://huggingface.co/privacy 。モデルは整合性検証後に端末に保存され、解析は端末上で実行され、質問、ウェブ構造、カスタムコードをAIクラウドサービスに送信しません。本機能はAPIキー不要で、AI設定でダウンロード済みモデルを削除可能です。64ビット対応端末と十分なストレージ・メモリが必要です。

OpenRouterクラウドモデル
OpenRouter APIキーを入力すると、キーはAndroid Keystoreで保護され端末に保存されます。あなたがデータ送信に同意し解析ボタンを押した時のみ、現在のドメイン、限定されたコンポーネント構造、保存済みカスタムCSS／JS／HTMLとコンポーネントルール、入力した質問がOpenRouterと選択したモデルプロバイダーに送信され、SkyEyeルールの検査に使われます。通常のSkyEye解析は限定構造のみ使用します。「AIルール修正」では今回の同意後に現在の文書読み込み時の限定的な生HTMLと現在の編集内容も送信します。HTMLはフォームコントロール内容、編集可能領域、script、イベント属性、URL属性のクエリパラメータを除外しますが、個人情報を含む可能性があります。このスナップショットはページメモリにのみ保持され、ディスクには書き込みません。アプリはフォーム値やCookieを読み取りませんが、質問、コンポーネント名、ルール、カスタムコードにあなたやサイトが入力した個人情報が含まれる可能性があります。編集済みHTMLも元のコンポーネントテキストを含む場合がありますので内容を確認してください。APIキーはOpenRouter認証に使われ、ウェブには提供されません。アプリはOpenRouterにdata_collection=denyを指定し、データ収集を許可するモデルプロバイダーパスを除外します。OpenRouterのアカウント記録、料金、その他のデータ処理はそのポリシーとアカウント設定に従います。ポリシー：https://openrouter.ai/privacy

ウェブサイト閲覧とバージョン照会
ページを開くと、そのサイトと読み込み元にネットワークリクエスト、IPアドレス、ブラウザ識別子、適用されるCookieが送信されます。アドレスバーから検索語を送信すると、URLエンコードされて選択したGoogle、Bing、Yahoo、百度、Naver、中国語ウィキペディア、またはカスタムHTTPS検索サービスに送信されます。検索結果、利用可能地域、データ処理は各サービスのポリシーに従います。最新のChromiumバージョン照会はGoogleのバージョンサービスに接続し、AIモデルリストの手動更新はOpenRouterに接続します。HTTP／HTTPSファイルはAndroidダウンロードサービスが処理し、ページ生成のblob／dataファイルはアプリがローカルで分割書き込みしDownloads/ChengJingに保存、アプリのサーバーにはアップロードしません。この種のダウンロードは元タブが利用可能である必要があり、キャンセルや中断時は未完了出力をクリアします。ダウンロードファイルと記録は端末に保持され、シークレットタブのクリアでは消えません。新しいキャッシュファイルのダウンロードはシークレット元URLを保存しません。画像の長押しは検証後に保存し、ブックマークのインポート・エクスポートはシステム選択ファイルのみ使用します。

接続とカスタムコード
Google同期とOpenRouterのネイティブ接続はHTTPS証明書検証を使用します。ウェブ閲覧は証明書をデフォルト検証し、アドレスバーの接続アイコンから特定のHTTPSホスト名（異なるポート含む、他のサブドメインは除く）の恒久例外を手動で許可できます。例外はアプリ終了まで保持され、サイト認証保証が低下し、アドレスバーに警告が表示されます。HTTPサイトは暗号化されません。追加したJavaScriptは該当ページのコード権限を持ち、ページ内容の読み取りやリクエスト送信が可能です。用途が分かるコードのみ使用してください。

保存、停止、削除
ローカルデータは各機能で管理されます。閲覧履歴は最大250ページ、検索語は最大100件保存。サイトアイコンキャッシュは最大30日、256件、8MiB、ページキャッシュはWebViewの容量管理に従います。閲覧履歴は履歴削除で消去、ブックマークやお気に入りは項目削除で消去、ドメインルールは設定削除で消去、AI設定はAPIキー削除で消去、接続アイコンからサイト証明書例外を解除可能です。オフライン端末で削除済みお気に入りが再追加されるのを防ぐため、削除後も元フィールドと削除状態を含む同期記録を保持し、一覧には表示されません。全ローカルデータ（サイトCookie、ストレージ、同期削除記録含む）を削除するには、Androidの「設定 → アプリ → 澄境ブラウザ → ストレージ → データを消去」かアンインストールを行ってください。これによりアプリがリセットされるため、必要なブックマークは事前にエクスポートしてください。

「同期停止とログアウト」は本アプリの同期のみ停止し、ローカルとGoogle Driveのブックマーク、お気に入り、読書進捗、サイト設定は保持します。クラウドデータを削除するには、全端末で同期停止後、Google Driveウェブ版の「設定 → アプリ管理 → 澄境ブラウザ」から非表示のアプリデータを削除してください。Googleアカウントのサードパーティ接続ページでアクセス権を取り消すことも可能です。再連携した端末は選択した同期ローカルデータを再アップロードする場合があります。OpenRouterやモデルプロバイダーに送信済みデータは各サービスの方法で処理または削除依頼してください。開発者はあなたの端末、Google Drive、個人OpenRouterアカウントのデータを直接読み取りや削除できません。

ポリシー変更と連絡
データ利用が変更された場合、本説明を更新します。新たな権限が必要な機能は別途同意を求めます。データ処理の問題や削除方法が不明な場合はadmin@techtarian.comまでご連絡ください。パスワードやAPIキーは送らないでください。

デフォルト検索エンジン（1.9.0）
設定 → ブラウズでGoogle、Bing、Yahoo、百度、Naver、中国語ウィキペディア、または{query}を1回含むHTTPS検索URLテンプレートを指定可能。Googleがデフォルトです。選択とカスタムテンプレートは端末に保存されGoogle同期には含まれません。アプリデータ削除やアンインストールで削除されます。アドレスバーはローカルで明確なURLと検索語を判別し、入力中の内容はオンライン候補サービスに送信しません。検索送信時のみ検索語が選択サービスに送信されます。シークレットモードは同じ設定を使いますが検索語をローカル閲覧履歴に追加しません。カスタムサービスは利用者が選択し、URLとプライバシーポリシーを確認してください。

シークレットタブとダウンロードリスト（1.4.0）
シークレットタブは通常タブと異なるWebViewプロファイルを使い、Cookie、キャッシュ、サイトストレージを共有しません。ローカル閲覧・検索履歴に追加せず、タブURLを保存せず復元もせず、タブプレビューも生成しません。全シークレットタブを閉じるとこのプロファイルのCookie、ネットワークキャッシュ、サイトストレージのクリアを要求します。クリアは非同期処理です。異常終了時は次回起動時に古いシークレットプロファイルをクリアし、そのセッションは使いません。これはOSや物理フォレンジックに対し完全な匿名性を保証せず、サイト、雇用主、ネットワークプロバイダーへの活動は隠しません。
ユーザーが作成したブックマーク、お気に入り、サイトルール、システムダウンロードは保持されます。シークレットダウンロード前にファイルとシステムダウンロード記録の保存を再通知します。システム共有やAI解析などの積極的な送信は元の確認とサービスポリシーに従います。Android System WebViewのデータ分離とクリアに対応しない場合は更新を促し、通常タブをシークレットに偽装しません。
ダウンロードリストは本アプリが作成したシステムダウンロード記録のみ照会し、他アプリのファイルはスキャンしません。システムで削除された記録は復元保証されません。通常タブのプレビューは現在ページの可視内容を含む場合があり、1.4.1以降はアプリの内部専用領域に保存され、タブと共に保持され、対応タブ閉鎖時に削除されます。アプリ再起動では削除されません。プレビューはGoogle同期に含まれず、アルバムやDownloadsにも入らず、システムバックアップから除外されます。シークレットタブはプレビューを生成・保存しません。アプリの全データ削除やアンインストールでこれらのローカルプレビューは削除されます。

ホームと毎日の一句
ホームボタンのオンオフ、カスタムホームURL、初回説明の閲覧有無、毎日の一句の開始日は端末にのみ保存されGoogle同期に含まれません。89句のテキストはアプリにオフラインで提供され、いかなるサービスにも問い合わせや読書記録のアップロードを行いません。カスタムホームを積極的にクリックすると該当サイトに通常の閲覧リクエストを送信します。シークレットタブは独立したサイトデータを使います。アプリデータ削除でこれらのローカル設定もリセットされます。

閲覧データ削除（1.6.0）
機能メニューで期間を選択し、ローカルの閲覧・検索履歴を削除、または期間内に最後に閲覧した通常タブを閉じてそのプレビューを削除できます。時間情報は端末にのみ保存されGoogle同期に含まれません。旧版で時間未記録のデータは「期間なし」でのみ削除されます。Cookie、キャッシュ、サイトデータは別途すべて選択してクリア可能で、デフォルトは未選択、選択期間の制限を受けません。これによりログアウトする場合があります。この操作はブックマーク、お気に入り、ダウンロードファイル、SkyEye設定、シークレットセッションを保持します。シークレットデータはシークレットタブ閉鎖で削除されます。

他アプリの起動（1.7.0）
ウェブ内で外部アプリリンクを積極的にクリックした場合や、Androidが指定したアプリ処理の通常URLは澄境が対応アプリに渡します。相手アプリはポリシーに従いリンクや利用記録を保存する可能性があります。澄境は閲覧Cookie、履歴、APIキーを提供しません。シークレットモード離脱前に通知します。澄境はHTTP/HTTPSリンクの処理アプリのみ照会し、インストール済みアプリリストは保存・送信しません。対応アプリ未インストールで有効なウェブ代替がある場合は元タブで開きます。

画像操作（1.8.0）
画像の長押しでプレビュー、コピー、ダウンロード、共有、新タブで開くが可能です。画像取得リクエストは該当タブのCookieとブラウザ識別子を使用します。画像は端末に一時保存され、単一画像は最大32MiB、通常キャッシュは最大128MiB、シークレットは最大64MiBで、起動時と書き込み時に24時間超のファイルを削除します。Cookie、キャッシュ、サイトデータクリア時に通常画像キャッシュも削除されます。システムはより早くキャッシュを回収する場合があります。Downloadsへのダウンロードファイルはユーザーが保持または削除します。新しい画像ダウンロード記録は最大500件でGoogle同期に含まれません。コピーと共有は該当画像の一時読み取り権限で実ファイルを提供し、受け取りアプリは独自ポリシーでコピーを保持する可能性があります。シークレットプレビューは全シークレットタブ閉鎖時に削除され、シークレットコピー、ダウンロード、共有は事前に外部保存の可能性を通知します。data:／blob:の一時画像タブは保存されず復元できず、画面で先にダウンロードを促します。

サイト位置情報（1.11.0）
サイトが位置情報を要求し、あなたがそのサイトとAndroidの位置権限を許可した場合のみ、WebViewは端末の位置情報をサイトに提供します。概略または正確な位置を選択可能です。アプリはバックグラウンド位置情報を要求せず、座標を保存せず、開発者、Google同期、AIサービスに位置情報を送信しません。サイトの位置利用はそのポリシーに従います。通常のサイト位置許可はローカルにのみ保存され、アドレスバーのサイト情報から変更可能でGoogle同期に含まれません。シークレット許可は通常タブと分離され、全シークレットタブ閉鎖やアプリ終了時にクリアされます。Android設定でアプリの位置権限を取り消すことも可能です。アプリデータ削除やアンインストールでローカル許可は削除されます。

Android直接位置情報（1.11.1）
サイトとAndroidの許可取得後、澄境はAndroidのGPS、ネットワーク、システム融合位置情報ソースから直接位置を取得し、現在のサイトに提供します。サイトは単発または継続的な位置要求が可能で、キャンセル、ページ切替、タブ閉鎖、フォアグラウンド離脱時に関連要求を停止します。単発要求は最大2分待機し、サイト設定により短縮される場合があります。位置モジュールは座標をメモリ内で短時間のみ使用し、記録や同期は行いません。サイトに表示される位置情報はウェブコンテンツであり、通常タブのプレビューは既存ルールで可視画面を保持し、シークレットタブはプレビューを生成しません。システムは最近の位置を保存する場合があり、サイトが明確に許容する期間内のみ使用します。サイト位置許可、シークレット隔離、Google／AI同期非参加の原則は変わりません。
