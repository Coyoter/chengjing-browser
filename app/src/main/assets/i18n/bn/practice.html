ChengJing・SkyEye অনুশীলন ক্ষেত্রস্থানীয় প্রদর্শনী ওয়েবপেজ
সাধারণ তথ্য ব্যানার · আপনি রাখতে পারেন
ধীরে করুন, ভালো করে দেখুন

ওয়েবপেজটি আপনার অভ্যাসমতো সাজান।

এটি মোবাইলে অনুশীলনের ওয়েবপেজ। আপনি উপাদানগুলি সামঞ্জস্য করতে পারেন, নিজের স্টাইল ও পেজ বিষয়বস্তু যোগ করতে পারেন।

টুলবারের 'SkyEye' চাপুন, চালু করে উপাদান নির্বাচন করুন। যদি শুধু টেক্সট নির্বাচন হয়, 'বাহিরের এক স্তর নির্বাচন করুন' চাপুন যতক্ষণ না পুরো উপাদান ঘেরা হয়, তারপর পূর্বদর্শন করে অপসারণ করুন।

ওয়েবপেজের মূল বিষয়বস্তু হওয়া উচিত আপনি যা দেখতে চান।

নিজের কিছু যোগ করুন

SkyEye চালু করে 'নতুন CSS যোগ করুন' নির্বাচন করলে স্টাইল সামঞ্জস্য করা যায়। যেমন অনুচ্ছেদগুলোকে বেশি ফাঁকা করতে:

main { line-height: 2; }

'নতুন JS যোগ করুন' নির্বাচন করলে পেজে পড়ার স্মরণিকা যোগ করা যায়:

if (!document.getElementById("my-note")) {
  const note = document.createElement("p");
  note.id = "my-note";
  note.textContent = "একটু বিশ্রাম নিন";
  document.querySelector("main").prepend(note);
}

অপসারণের পর কী হবে?

নিয়ম সংরক্ষণ করুন, তারপর দ্বিতীয় পৃষ্ঠায় যান। উপাদানের বিষয়বস্তু আলাদা হলেও, কাঠামো একই থাকলে এটি আপনাকে বিরক্ত করবে না।

একই ডোমেইনের দ্বিতীয় পৃষ্ঠায় যান →

মেনু থেকে 'অস্থায়ীভাবে মূল সাইট দেখান' নির্বাচন করেও মূল সাইট সাময়িক দেখতে পারেন। সব নিয়মই থাকবে, পুনরায় সেট করতে হবে না।
