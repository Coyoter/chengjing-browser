Ajuste a página para o seu hábito.

Esta é uma página de prática no celular. Você pode ajustar componentes e adicionar seus próprios estilos e conteúdos.

Toque em “SkyEye” na barra de ferramentas, depois selecione um componente. Se selecionar apenas texto, toque em “Selecionar camada externa” até envolver o componente inteiro, então visualize e remova.

O protagonista da página deve ser o conteúdo que você quer ver.

Adicione um pouco do seu próprio conteúdo

Abra SkyEye, escolha “Adicionar CSS” para ajustar estilos. Por exemplo, para espaçar melhor os parágrafos:

main { line-height: 2; }

Escolha “Adicionar JS” para inserir um lembrete de leitura na página:

if (!document.getElementById("my-note")) {
  const note = document.createElement("p");
  note.id = "my-note";
  note.textContent = "Lembre-se de fazer pausas";
  document.querySelector("main").prepend(note);
}

E depois de remover?

Salve as regras e vá para a segunda página. Mesmo com conteúdos diferentes, se a estrutura for igual, elas não vão te incomodar.
