ChengJing Browser | Privacy and Data
Last updated: September 27, 2026
Developer: Coyoter
Contact: admin@techtarian.com

Data stored on your device
Bookmarks, favorites and reading progress, browsing history, address bar search terms, open tabs, default search engine and custom search URL templates, site rules, custom CSS/JS/HTML, appearance and site certificate exceptions are stored locally. Sites may save cookies, cache, and storage data via WebView. Address bar suggestions are matched locally from search terms and browsing history; input text is not sent to suggestion services until you submit a search. Bookmarks and favorites cache site icons; if missing, icons may be requested directly from the site’s /favicon.ico without using third-party proxies or sending full bookmark paths or URL parameters. This data is not automatically sent to the developer’s servers by installing this app. The app has no built-in account system or usage statistics/error reporting services.

Google bookmarks, favorites, and SkyEye settings sync (optional)
Only after linking your Google account does the app use drive.appdata permission to read/write this app’s hidden Google Drive space; it does not access other Drive files. Synced data includes bookmark names, URLs, folders, modification and deletion records, and sync device IDs generated by the app. Favorites sync IDs, custom names, current reading URLs, page titles, scroll positions, reading percentages, modification times, and deletion status. Google account IDs and emails identify the sync account. Enabling “Sync SkyEye site settings” also syncs domains, component rules, custom CSS/JS/HTML, site behavior settings, and modification/deletion status; code may contain private content, so verify first. Browsing history, address bar search terms, search engine choices and custom templates, temporary exceptions, certificate exceptions, and OpenRouter keys are not synced. Sync may occur automatically when the app opens or selected data changes. The newest complete record of a favorite is used; it does not enforce highest reading percentage or force page jumps. Older app versions do not sync favorites; update all devices to supported versions for sync.

Google data use is limited to requested sync functions, complying with Google API Services User Data Policy including Limited Use; Google account or cloud sync data is not shared with AI providers for model training. Google services handle data per their privacy policy: https://policies.google.com/privacy

AI assistance (optional)
You may opt out of AI or choose local Gemma 4 E2B or OpenRouter.

Gemma 4 local model
Only after you initiate download does Android download service fetch about 2.59 GB model from Hugging Face’s LiteRT community repository; source receives IP and download request, handled per https://huggingface.co/privacy. After integrity check, model is stored locally; analysis runs on device without sending queries, page structure, or custom code to AI cloud. No API key needed; you can delete downloaded models in AI settings. Requires compatible 64-bit device with sufficient storage and memory.

OpenRouter cloud model
After entering OpenRouter API key, it is protected by Android Keystore and stored locally. Only with your consent and analysis request are current domain, limited component structure, saved custom CSS/JS/HTML and component rules, and your input sent to OpenRouter and chosen model providers for SkyEye rule checks. General SkyEye analysis uses limited structure; in “AI rule revision,” with your consent, current document load, pre-SkyEye limited raw HTML snapshot, and current edits are sent. HTML excludes form controls, editable areas, scripts, event attributes, and URL query parameters but may include private page text; this snapshot remains in page memory only, not saved to disk. The app does not read form values or cookies; however, questions, component names, rules, and custom code may contain personal data you or sites entered; edited HTML may include original component text—please verify. API key authenticates with OpenRouter, not provided to webpages. The app sets data_collection=deny to exclude models allowing data collection. OpenRouter account logs, billing, and data handling follow their policies and account settings. Policy: https://openrouter.ai/privacy

Browsing sites and version queries
Opening a webpage sends network requests, IP, browser ID, and applicable cookies to the site and its resources. Search terms submitted from the address bar are URL-encoded and sent to your chosen Google, Bing, Yahoo, Baidu, Naver, Chinese Wikipedia, or custom HTTPS search service; results, regions, and data handling follow that service’s policies. Chromium version queries connect to Google’s version service; manual AI model list updates connect to OpenRouter. HTTP/HTTPS files are handled by Android download service; blobs/data files generated by pages are saved locally in Downloads/ChengJing in segments, not uploaded to app servers. Such downloads require source tabs to remain available; cancellations or interruptions clean incomplete outputs. Downloaded files and records remain on device, not cleared by incognito tabs; new temp file downloads do not save incognito source URLs. Long-pressing images verifies before saving; bookmark import/export uses system-selected files only.

Connections and custom code
Google sync and OpenRouter native connections use HTTPS certificate verification. Browsing verifies certificates by default; you may manually allow permanent HTTPS exceptions for specific hostnames (including ports, excluding other subdomains) via the address bar connection icon. Exceptions persist until app closure, reducing site identity assurance and showing warnings in the address bar. HTTP sites are unencrypted. Added JavaScript has page code capabilities and may read content or send requests; use only code you understand.

Saving, stopping, and deleting
Local data is managed by features. Browsing history keeps up to 250 recent pages, search terms up to 100; site icon cache keeps up to 30 days, 256 entries, and 8 MiB; page cache managed by WebView capacity. You can clear history records, delete bookmarks/favorites, remove domain rules, delete API keys in AI settings, or disable site certificate exceptions via connection icon. To prevent deleted favorites from reappearing offline, deletion retains sync records with original fields and deletion status; they no longer show in favorites lists. To remove all local data (including site cookies, storage, and sync deletion records), use Android Settings → Apps → ChengJing Browser → Storage → Clear data, or uninstall; this resets the app, so export needed bookmarks first.

“Stop sync and log out” halts app sync but retains local and Google Drive bookmarks, favorites, reading progress, and site settings. To delete cloud data, stop sync on all devices, then delete hidden app data in Google Drive web under Settings → Manage apps → ChengJing Browser; you may also revoke access on Google account’s third-party connections page. Re-linking devices with data may re-upload selected local sync data. Data sent to OpenRouter or model providers must be handled or deletion requested per their services. Developers cannot directly read or delete your phone, Google Drive, or personal OpenRouter account data.

Policy changes and contact
If data use changes, this notice updates; new authorized features require separate consent. For data handling questions or deletion requests, email admin@techtarian.com; do not provide passwords or API keys.

Default search engines (1.9.0)
Settings → Browsing lets you choose Google, Bing, Yahoo, Baidu, Naver, Chinese Wikipedia, or provide your own HTTPS search URL template with a single {query}. Google is default. Choices and custom templates are stored locally, not synced with Google; clearing app data or uninstalling removes them. The address bar locally distinguishes URLs from search terms; input is not sent to online suggestion services until search submission. Incognito uses the same settings but does not add search terms to local history. Custom services are your choice; verify their URLs and privacy policies.

Incognito tabs and download list (1.4.0)
Incognito tabs use a separate WebView profile, not sharing cookies, cache, or site storage. They do not add to local browsing or search history, do not save tab URLs for restoration, nor generate tab preview thumbnails. Closing all incognito tabs triggers asynchronous clearing of that profile’s cookies, network cache, and site storage. If the process crashes, the next launch clears old incognito profiles and discards that session. This does not guarantee full invisibility to OS or forensic tools, nor hide your activity from sites, employers, or ISPs.
Bookmarks, favorites, site rules, and system downloads you create remain. Incognito downloads warn again about file and system download record retention; system sharing, AI analysis, and other active transmissions follow original confirmations and service policies. Android System WebView supporting data isolation and clearing is required; if unsupported, update prompts appear, and incognito is not faked by normal tabs.
The download list queries only system download records created by this app, not scanning other apps’ files; records removed by the system may not be recoverable. Normal tab previews may include visible page content; since 1.4.1, these are stored in the app’s internal private space, retained with tabs, deleted when tabs close; reopening the app does not delete them. Snapshots are not synced with Google, not placed in albums or Downloads, and excluded from system backups. Incognito tabs do not generate or save snapshots. Clearing all app data or uninstalling deletes these local snapshots.

Home page and daily quotes
Home button toggle, custom home URL, first-time tutorial viewed status, and daily quote start date are stored locally, not synced with Google. 89 quotes are provided offline with the app, no queries or uploads of reading records to any service. Clicking custom home sends a normal browsing request to that site; incognito tabs use separate site data. Clearing app data resets these local settings.

Deleting browsing data (1.6.0)
The menu lets you select a time range to delete local browsing/search history or close last viewed normal tabs in that range and delete their snapshots. Time info is stored only locally, not synced. Older data without timestamps deletes only under “all time.” Cookies, cache, and site data are separately selectable for full clearing, unchecked by default and not limited by time range; this may log you out of sites. This preserves bookmarks, favorites, downloads, SkyEye settings, and incognito sessions; incognito data clears by closing incognito tabs.

Opening other apps (1.7.0)
Clicking external app links in webpages or Android-handled URLs passes links to corresponding apps. Those apps may save links and usage per their policies; ChengJing does not provide browsing cookies, history, or API keys. Incognito mode warns before leaving, as external apps are not controlled by ChengJing’s incognito clearing. ChengJing queries only handlers for HTTP/HTTPS links, does not save or upload installed app lists. If no app is installed and the link has a valid web fallback, it opens in the current tab.

Image operations (1.8.0)
Long-press images to preview, copy, download, share, or open in new tabs. Image requests use the tab’s cookies and browser ID; images are cached locally, max 32 MiB per image, 128 MiB general cache, 64 MiB incognito, clearing files older than 24 hours on startup and writes. Clearing cookies, cache, and site data also clears general image cache. The system may reclaim cache earlier; files downloaded to Downloads are kept or deleted by you. New image download records keep up to 500 entries, not synced with Google. Copy and share provide real files via temporary read permissions limited to that image; receiving apps may keep copies per their policies. Incognito previews clear when all incognito tabs close; incognito copy, download, or share warn about possible external retention. data:/blob: temporary image tabs do not save for restoration; prompts appear to download first.

Site location (1.11.0)
WebView provides location to sites only if the site requests it and you grant both site and Android location permissions. You may choose approximate or precise location; the app does not request background location, does not save coordinates, nor send location to developers, Google sync, or AI services. Site use of location follows their policies. Normal site location permissions are stored locally and can be changed via site info in the address bar; not synced with Google. Incognito permissions are separate and cleared when all incognito tabs close or the app exits. You may revoke app location permissions in Android settings; clearing app data or uninstalling removes local permissions.

Android direct location (1.11.1)
With site and Android permissions, ChengJing requests location directly from Android GPS, network, or fused sources, then provides it to the current site. Sites may request single or continuous location; requests stop on cancel, page change, tab close, or app backgrounding. Single requests wait up to two minutes, possibly shorter per site settings. Location modules only temporarily hold coordinates in memory, no separate recording or syncing. Site-displayed location info remains page content; normal tab previews keep visible content per existing rules; incognito tabs do not generate previews. The system may save recent locations, used only within site-accepted timeframes. Site location permissions, incognito isolation, and no Google/AI sync principles remain unchanged.

Разрешения сайта (1.14.0)
Сайты используют камеру и микрофон только после разрешений сайта и Android. Выбранные медиа и файлы обрабатывает сайт, без отправки разработчику, синхронизации Google Drive или ИИ. Снимки временно хранятся локально: обычные старше 24 часов удаляются при следующем запуске или съёмке, приватные — при закрытии всех приватных вкладок или следующем запуске. Лицензии защищённых медиа обрабатывают сайт и устройство. Разрешения и сторонние cookie остаются локально; приватные настройки не сохраняются постоянно.
