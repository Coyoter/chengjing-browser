Настройте страницу под свои привычки.

Это тренировочная страница на телефоне. Вы можете настраивать элементы, добавлять свои стили и содержимое.

Нажмите «SkyEye» на панели инструментов, затем выберите элемент. Если выбран только текст, нажмите «Выбрать внешний слой», пока не выделите весь элемент, затем просмотрите и удалите.

Главным на странице должно быть то, что вы хотите видеть.

Добавьте немного своего

Откройте SkyEye, выберите «Добавить CSS», чтобы изменить стиль. Например, сделать абзацы более просторными:

main { line-height: 2; }

Выберите «Добавить JS», чтобы добавить на страницу напоминание о чтении:

if (!document.getElementById("my-note")) {
  const note = document.createElement("p");
  note.id = "my-note";
  note.textContent = "Не забывайте делать перерывы";
  document.querySelector("main").prepend(note);
}

Что дальше после удаления?

Сохраните правило и перейдите на вторую страницу. Хотя содержимое элементов разное, если структура совпадает, они не будут вас беспокоить.

Перейти на вторую страницу того же домена →

Также можно выбрать в меню «Временно показать оригинальный сайт», чтобы временно вернуться к исходной странице. Все правила сохраняются, перенастраивать не нужно.
