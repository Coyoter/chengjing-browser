Adaptez la page web à votre habitude.

Ceci est une page d'entraînement sur votre téléphone. Vous pouvez ajuster les composants et ajouter vos propres styles et contenus.

Appuyez sur « SkyEye » dans la barre d'outils, puis sélectionnez un composant. Si vous ne sélectionnez que du texte, appuyez sur « Sélectionner le conteneur parent » jusqu'à encadrer tout le composant, puis prévisualisez la suppression.

Le protagoniste de la page web devrait être le contenu que vous souhaitez voir.

Ajoutez un peu de votre touche personnelle

Ouvrez SkyEye, choisissez « Ajouter CSS » pour ajuster le style. Par exemple, pour espacer davantage les paragraphes :

main { line-height: 2; }

Choisissez « Ajouter JS » pour insérer un rappel de lecture sur la page :

if (!document.getElementById("my-note")) {
  const note = document.createElement("p");
  note.id = "my-note";
  note.textContent = "N'oubliez pas de faire une pause";
  document.querySelector("main").prepend(note);
}

Et après la suppression ?

Enregistrez la règle, puis passez à la deuxième page. Même si le contenu des composants change, tant que la structure est identique, cela ne vous dérangera pas.
