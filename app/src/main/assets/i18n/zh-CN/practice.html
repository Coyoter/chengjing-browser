把网页调成习惯的样子。

这是手机里的练习网页。你可以调整组件，也能加入自己的样式与页面内容。

点工具栏的「天眼」，开启后点击组件。若只选到文字，按「选取外面一层」，直到框住整块组件，再预览移除。

网页的主角，应该是你想看的内容。

新增一点自己的东西

打开天眼，选「新增 CSS」就能调整样式。例如让段落更宽松：

main { line-height: 2; }

选「新增 JS」，可以在页面加入阅读提醒：

if (!document.getElementById("my-note")) {
  const note = document.createElement("p");
  note.id = "my-note";
  note.textContent = "记得休息一下";
  document.querySelector("main").prepend(note);
}

移除之后呢？

保存规则，再前往第二页。虽然组件内容不同，只要结构相同，它依然不会打扰你。

前往同网域第二页 →
