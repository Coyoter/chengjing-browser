保存在手机上的数据
书签、收藏与阅读进度、浏览记录、网址栏搜索词、已开标签页、默认搜索引擎及自定义搜索网址模板、网站规则、自定义 CSS／JS／HTML、外观与网站凭证例外保存在手机。网站可能通过 WebView 保存 Cookie、缓存与网站存储数据。网址栏建议由本机的搜索词及浏览记录比对，不会将正在输入的文字发送给建议服务；只有你提交搜索后，搜索文字才会发送给所选的搜索服务。书签与收藏会缓存浏览时获取的网站图标；无图标时可能直接向该网站的 /favicon.ico 请求图标，不会使用第三方图标代理，也不会为此发送完整书签路径或网址参数。这些数据不会因安装本应用就自动发送到开发者的服务器。本应用没有自建账户系统，也没有内建使用行为统计或错误回报服务。

Google 书签、收藏与天眼设置同步（自行选择）
只有在你连接 Google 后，应用才会使用 drive.appdata 权限，读写这个应用专用的 Google Drive 隐藏数据空间；不读取你的其他 Drive 文件。同步数据包括书签名称、网址、文件夹、修改与删除记录，以及应用产生的同步设备识别码。收藏会同步识别码、自定义名称、当前阅读网址、页面标题、滚动位置、阅读百分比、修改时间及删除状态。Google 账户识别码及电子邮件用于识别同步账户。另外开启“同步天眼网站设置”后，会同步域名、组件规则、自定义 CSS／JS／HTML、网站行为设置及修改与删除状态；代码可能含有私人内容，请先确认。浏览记录、网址栏搜索词、搜索引擎选择与自定义模板、暂时例外、凭证例外及 OpenRouter 金钥不加入同步。应用开启及所选同步数据异动时可能自动同步。同一收藏以较新的完整保存记录为准；不会强制采用最高阅读百分比，也不会强制跳转正在浏览的页面。旧版应用不会同步收藏，请在所有需要同步收藏的设备更新至支持版本。

Google 数据的使用仅限你要求的同步功能，遵守 Google API Services User Data Policy，包括 Limited Use 要求；不将 Google 账户或云端同步数据交给 AI 供应商做模型训练。Google 提供的服务依其隐私权政策处理数据：https://policies.google.com/privacy

AI 协助（自行选择）
你可以不使用 AI，也可以选择本机 Gemma 4 E2B 或 OpenRouter。

Gemma 4 本机模型
只有你按下下载后，才会通过 Android 下载服务从 Hugging Face 的 LiteRT 社区模型仓库获取约 2.59 GB 的模型；下载来源会收到 IP 地址及下载请求，依其隐私权政策处理：https://huggingface.co/privacy 。模型经完整性核对后保存在手机，分析在设备上执行，不会把问题、网页结构或自定义代码发送至 AI 云端服务。本机功能不需要 API Key；你可以在 AI 设置删除下载的模型。需要兼容的 64 位设备及足够的存储空间与内存。

OpenRouter 云端模型
输入 OpenRouter API Key 后，金钥会以 Android Keystore 保护并保存在手机。只有你同意数据传送并按下分析，才会将当前域名、有限的组件结构、已保存的自定义 CSS／JS／HTML 与组件规则，以及你输入的问题发送给 OpenRouter 与所选模型供应商，用于检查天眼规则。一般天眼分析只使用有限结构；在“AI 修订规则”中，经你本次同意后，还会发送当前文档加载、应用天眼前截取的有限原始 HTML 与当前编辑内容。HTML 会排除表单控件内容、可编辑区、script、事件属性与 URL 属性中的查询参数，但可能包含私人页面文字；这份快照只保留于页面内存，不写入磁盘。应用不读取表单值或 Cookie；但问题、组件命名、规则与自定义代码可能含有你或网站填写的个人资料；编辑过的 HTML 也可能包含组件原有文字，请先确认内容。API Key 用于向 OpenRouter 验证身份，不提供给网页。应用向 OpenRouter 指定 data_collection=deny，排除允许收集数据的模型供应路径。OpenRouter 本身的账户记录、费用及其他数据处理仍依其政策与账户设置。政策：https://openrouter.ai/privacy

浏览网站及查询版本
开启网页时，该网站及其加载来源会收到网络请求、IP 地址、浏览器识别与适用的 Cookie。当你从网址栏提交搜索文字时，文字会经网址编码后发送给你选择的 Google、Bing、Yahoo、百度、Naver、中文维基百科或自定义 HTTPS 搜索服务；搜索结果、可用地区与数据处理由该服务的政策规范。查询最新 Chromium 版本会连接至 Google 的版本服务；手动更新 AI 模型列表会连接至 OpenRouter。HTTP／HTTPS 文件由 Android 下载服务处理；网页产生的 blob／data 文件由应用在本机分段写入 Downloads/ChengJing，不会上传到本应用的服务器。这类下载需要来源标签页保持可用，取消或中断时会清理未完成输出。下载文件及记录会保留在手机，不随无痕标签页清除；新缓存文件下载不保存无痕来源网址。长按图片仍会验证图片后保存，书签导入与导出只使用你通过系统选择的文件。

连接与自定义代码
Google 同步与 OpenRouter 的原生连接使用 HTTPS 证书验证。网页浏览默认验证证书；你可以从网址栏的连接图标手动允许特定 HTTPS 主机名的永久例外（包含其不同连接端口，不含其他子网域）。例外会持续保存到你关闭，降低网站身份验证保障，网址栏会显示警示。HTTP 网站本身不加密。你加入的 JavaScript 具有该网页代码的能力，可能读取页面内容或发送请求，请只使用你了解用途的代码。

保存、停止与删除
本机数据由各功能管理。浏览记录最多保留最近 250 个页面，搜索词最多 100 条；网站图标缓存最多保存 30 天、256 条及 8 MiB，网页缓存由 WebView 的容量机制管理。你可以在浏览记录清除记录，在书签或收藏删除项目，在域名规则删除设置，在 AI 设置移除 API Key，或从连接图标关闭网站凭证例外。为避免离线设备把已删除的收藏重新加回，收藏删除后会保留带有原始字段及删除状态的同步记录；它不再显示于收藏列表。若要移除全部本机数据（包括网站 Cookie、存储及同步删除记录），请使用 Android「设置 → 应用程序 → 澄境浏览器 → 存储空间 → 清除数据」，或卸载；这会重置应用，请先导出需要的书签。

“停止同步并登出”只停止本应用同步，会保留本机及 Google Drive 中的书签、收藏、阅读进度与网站设置。若要删除云端数据，先在所有设备停止同步，再于 Google Drive 网页版“设置 → 管理应用程序 → 澄境浏览器”删除隐藏的应用程序数据；也可在 Google 账户的第三方连接页面撤销访问权。重新连接仍有数据的设备时，可能重新上传所选同步的本机数据。已发送至 OpenRouter 或模型供应商的数据，需依该服务提供的方式处理或提出删除请求。开发者无法直接读取或代删你的手机、Google Drive 或个人 OpenRouter 账户数据。

政策变更与联系
数据用途若改变，会更新本说明；需要新增授权的功能会另行征求同意。数据处理问题或删除方式不明时，可寄信至 admin@techtarian.com；请勿提供密码或 API Key。

默认搜索引擎（1.9.0）
设置 → 浏览可选择 Google、Bing、Yahoo、百度、Naver、中文维基百科，或自行提供含有一次 {query} 的 HTTPS 搜索网址模板。Google 是默认值。选择及自定义模板保存在手机，不加入 Google 同步；清除 App 数据或卸载会一并移除。网址栏先在本机判断明确网址与搜索文字，正在输入的内容不会交给线上建议服务。只有提交搜索时，搜索文字才会传给所选服务。无痕使用相同设置，但不把搜索词加入本机浏览记录。自定义服务由你选择，请确认其网址及隐私政策。


无痕标签页与下载列表（1.4.0）
无痕标签页使用与一般标签页不同的 WebView Profile，不共享 Cookie、缓存与网站存储。不加入本机浏览或搜索记录，不保存标签页网址供重开恢复，也不产生标签页预览缩略图。关闭全部无痕标签页时会请求清理此 Profile 的 Cookie、网络缓存及网站存储；清理是异步工作。若进程异常终止，下一次启动会清理旧的无痕 Profile，且不再使用该工作会话。这不保证对操作系统或实体取证完全无痕，亦不隐藏你对网站、雇主或网络供应商的活动。
你主动建立的书签、收藏、网站规则及系统下载会保留。无痕下载前会再次告知文件及系统下载记录的保存；系统分享、AI 分析等主动外送行为仍依原本的确认与服务政策处理。需要支持数据隔离及清理的 Android System WebView，不支持时会提示更新，不以一般标签页伪装成无痕。
下载列表只查询此 App 建立的系统下载记录，不扫描手机其他 App 的文件；已被系统移除的记录不保证可恢复。一般标签页的预览快照可能包含当前页面的可见内容，自 1.4.1 起保存在 App 的内部专用空间，与标签页一起保留，关闭对应标签页时删除；重开 App 不会删除。快照不加入 Google 同步、不放入相册或 Downloads，并排除系统备份。无痕标签页仍不产生或保存快照。清除 App 全部数据或卸载会删除这些本机快照。

首页与每日一句
首页按钮开关、自定义首页网址、是否看过首次说明，以及每日句子的起始日期仅保存在手机，不加入 Google 同步。89 句文字随 App 离线提供，不向任何服务查询或上传阅读记录。主动点击自定义首页会向该网站发出一般浏览请求；无痕标签页仍使用独立网站数据。清除应用程序数据会一并重置这些本机设置。

删除浏览数据（1.6.0）
功能菜单可选择时间范围，删除本机浏览／搜索记录，或关闭该期间最后浏览的一般标签页并删除其快照。时间信息只存于手机，不加入 Google 同步。旧版未记录时间的数据只在“不限时间”删除。Cookie、缓存和网站数据另行勾选全部清除，默认不勾选，且不受所选时间范围限制；这可能登出网站。此操作保留书签、收藏、下载文件、天眼设置及无痕会话；无痕数据仍以关闭无痕标签页的方式清除。

开启其他 App（1.7.0）
在网页中主动点击外部 App 链接，或 Android 已指定交由 App 处理的一般网址，澄境会将链接交给对应 App。对方 App 可能依其政策保存链接及使用记录；澄境不提供浏览 Cookie、历史记录或 API Key。无痕模式离开前会提示，因为对方 App 不受澄境的无痕清理控制。澄境只查询 HTTP/HTTPS 链接的处理程序，不保存或上传已安装 App 列表。未安装对应 App 时，若链接包含有效网页备援，会在原标签页开启该网址。

图片操作（1.8.0）
长按图片可预览、复制、下载、分享或在新标签页开启。图片获取请求会使用该标签页的 Cookie 及浏览器识别；图片暂存在本机，单张最多 32 MiB，一般缓存最多 128 MiB、无痕最多 64 MiB，在启动及写入时清除超过 24 小时的文件。清除 Cookie、缓存和网站数据时也清除一般图片缓存。系统可能更早回收缓存；下载至 Downloads 的文件由你保留或删除。新的图片下载记录最多 500 条，不加入 Google 同步。复制与分享通过限于该图片的暂时读取权限提供真正文件，接收 App 可能依自身政策保留副本。无痕预览在关闭全部无痕标签页时清除；无痕复制、下载或分享会事先提示可能保留在外部。data:／blob: 的暂存图片标签页不保存供重开还原，画面会提示先下载。

网站定位（1.11.0）
只有网站请求位置且你允许该网站及 Android 定位权限后，WebView 才会将手机提供的位置交给该网站。你可以选择概略或精确位置；应用不要求后台定位、不自行保存坐标，也不将位置传送到开发者、Google 同步或 AI 服务。网站如何使用位置依其政策处理。一般网站定位授权仅保存在本机，可在网址栏的网站信息变更；不加入 Google 同步。无痕授权与一般标签页分开，关闭全部无痕标签页或结束应用程序后清除。你也可以在 Android 设置撤回 App 定位权限；清除 App 数据或卸载会移除本机授权。

Android 直接定位（1.11.1）
已获网站与 Android 授权后，澄境直接向 Android 的 GPS、网络或系统融合定位来源请求位置，再交给当前网站。网站可要求单次或持续位置；取消、换页、关闭标签页与离开前景时停止相关请求。一般单次请求最多等待两分钟，依网站设置可能更短。定位模块只短暂使用内存中的坐标，不另行记录或同步。网站呈现的位置资讯仍属网页内容，一般标签页预览依既有规则保留可见画面，无痕标签页不产生预览。系统可能保存最近位置；仅在网站明确接受的时效内使用。网站定位授权、无痕隔离及不加入 Google／AI 同步的原则维持相同。
