保存在手機上的資料
書籤、收藏與閱讀進度、瀏覽紀錄、已開分頁、網站規則、自訂 CSS／JS／HTML、外觀與網站憑證例外保存在手機。網站可能透過 WebView 保存 Cookie、快取與網站儲存資料。這些資料不會因安裝本應用就自動送到開發者的伺服器。本應用沒有自建帳戶系統，也沒有內建使用行為統計或錯誤回報服務。

Google 書籤與天眼設定同步（自行選擇）
只有在你連結 Google 後，應用才會使用 drive.appdata 權限，讀寫這個應用專用的 Google Drive 隱藏資料空間；不讀取你的其他 Drive 文件。同步資料包括書籤名稱、網址、資料夾、修改與刪除記錄，以及應用產生的同步裝置識別碼。Google 帳戶識別碼及電子郵件用於辨識同步帳戶。另外開啟「同步天眼網站設定」後，會同步網域、元件規則、自訂 CSS／JS／HTML、網站行為設定及修改與刪除狀態；程式碼可能含有私人內容，請先確認。收藏、瀏覽紀錄、暫時例外、憑證例外及 OpenRouter 金鑰不加入同步。應用開啟及所選同步資料異動時可能自動同步。

Google 資料的使用僅限你要求的同步功能，遵守 Google API Services User Data Policy，包括 Limited Use 要求；不將 Google 帳戶或雲端書籤交給 AI 供應商做模型訓練。Google 提供的服務依其隱私權政策處理資料：https://policies.google.com/privacy

AI 協助（自行選擇）
你可以不使用 AI。輸入 OpenRouter API Key 後，金鑰會以 Android Keystore 保護並保存在手機。只有你同意資料傳送並按下分析，才會將目前網域、有限的元件結構、已儲存的自訂 CSS／JS／HTML 與元件規則，以及你輸入的問題傳送給 OpenRouter 與所選模型供應商，用於檢查天眼規則。應用不主動擷取文章內文、表單值、Cookie 或網址參數；但問題、元件命名、規則與自訂程式碼可能含有你或網站填入的個人資料；編輯過的 HTML 也可能包含元件原有文字，請先確認內容。API Key 用於向 OpenRouter 驗證身分，不提供給網頁。應用向 OpenRouter 指定 data_collection=deny，排除允許收集資料的模型供應路徑。OpenRouter 本身的帳戶記錄、費用及其他資料處理仍依其政策與帳戶設定。政策：https://openrouter.ai/privacy

瀏覽網站及查詢版本
開啟網頁時，該網站及其載入來源會收到網路請求、IP 位址、瀏覽器識別與適用的 Cookie。這些網站的資料處理由各自的政策規範。查詢最新 Chromium 版本會連線至 Google 的版本服務；手動更新 AI 模型清單會連線至 OpenRouter。網頁下載由 Android 下載服務處理，書籤匯入與匯出只使用你透過系統選擇的檔案。

連線與自訂程式碼
Google 同步與 OpenRouter 的原生連線使用 HTTPS 憑證驗證。網頁瀏覽預設驗證憑證；你可以從網址列的連線圖示手動允許特定 HTTPS 主機名稱的永久例外（包含其不同連接埠，不含其他子網域）。例外會持續保存到你關閉，降低網站身分驗證保障，網址列會顯示警示。HTTP 網站本身不加密。你加入的 JavaScript 具有該網頁程式碼的能力，可能讀取頁面內容或發送請求，請只使用你了解用途的程式碼。

保存、停止與刪除
本機資料保留到你刪除為止。你可以在瀏覽紀錄清除記錄，在書籤或收藏刪除項目，在網域規則刪除設定，在 AI 設定移除 API Key，或從連線圖示關閉網站憑證例外。若要移除全部本機資料（包括網站 Cookie 與儲存），請使用 Android「設定 → 應用程式 → 澄境瀏覽器 → 儲存空間 → 清除資料」，或解除安裝；這會重設應用，請先匯出需要的書籤。

「停止同步並登出」只停止本應用同步，會保留本機及 Google Drive 中的書籤與網站設定。若要刪除雲端資料，先在所有裝置停止同步，再於 Google Drive 網頁版「設定 → 管理應用程式 → 澄境瀏覽器」刪除隱藏的應用程式資料；也可在 Google 帳戶的第三方連線頁面撤銷存取權。重新連結仍有資料的裝置時，可能重新上傳所選同步的本機資料。已傳送至 OpenRouter 或模型供應商的資料，需依該服務提供的方式處理或提出刪除請求。開發者無法直接讀取或代刪你的手機、Google Drive 或個人 OpenRouter 帳戶資料。

政策變更與聯絡
資料用途若改變，會更新本說明；需要新增授權的功能會另行徵求同意。資料處理問題或刪除方式不明時，可寄信至 admin@techtarian.com；請勿提供密碼或 API Key。
