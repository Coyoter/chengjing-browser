保存在手機上的資料
書籤、收藏與閱讀進度、瀏覽記錄、網址列搜尋詞、已開分頁、網站規則、自訂 CSS／JS／HTML、外觀與網站憑證例外保存在手機。網站可能透過 WebView 保存 Cookie、快取與網站儲存資料。網址列建議由本機的搜尋詞及瀏覽記錄比對，不會將正在輸入的文字傳送給建議服務。書籤與收藏會快取瀏覽時取得的網站圖示；沒有圖示時可能直接向該網站的 /favicon.ico 請求圖示，不會使用第三方圖示代理，也不會為此傳送完整書籤路徑或網址參數。這些資料不會因安裝本應用就自動送到開發者的伺服器。本應用沒有自建帳戶系統，也沒有內建使用行為統計或錯誤回報服務。

Google 書籤、收藏與天眼設定同步（自行選擇）
只有在你連結 Google 後，應用才會使用 drive.appdata 權限，讀寫這個應用專用的 Google Drive 隱藏資料空間；不讀取你的其他 Drive 文件。同步資料包括書籤名稱、網址、資料夾、修改與刪除記錄，以及應用產生的同步裝置識別碼。收藏會同步識別碼、自訂名稱、目前閱讀網址、頁面標題、捲動位置、閱讀百分比、修改時間及刪除狀態。Google 帳戶識別碼及電子郵件用於辨識同步帳戶。另外開啟「同步天眼網站設定」後，會同步網域、元件規則、自訂 CSS／JS／HTML、網站行為設定及修改與刪除狀態；程式碼可能含有私人內容，請先確認。瀏覽記錄、網址列搜尋詞、暫時例外、憑證例外及 OpenRouter 金鑰不加入同步。應用開啟及所選同步資料異動時可能自動同步。同一收藏以較新的完整儲存紀錄為準；不會強制採用最高閱讀百分比，也不會強制跳轉正在瀏覽的頁面。舊版應用不會同步收藏，請在所有需要同步收藏的裝置更新至支援版本。

Google 資料的使用僅限你要求的同步功能，遵守 Google API Services User Data Policy，包括 Limited Use 要求；不將 Google 帳戶或雲端同步資料交給 AI 供應商做模型訓練。Google 提供的服務依其隱私權政策處理資料：https://policies.google.com/privacy

AI 協助（自行選擇）
你可以不使用 AI，也可以選擇本機 Gemma 4 E2B 或 OpenRouter。

Gemma 4 本機模型
只有你按下下載後，才會透過 Android 下載服務從 Hugging Face 的 LiteRT 社群模型儲存庫取得約 2.59 GB 的模型；下載來源會收到 IP 位址及下載請求，依其隱私權政策處理：https://huggingface.co/privacy 。模型經完整性核對後保存在手機，分析在裝置上執行，不會把問題、網頁結構或自訂程式碼送至 AI 雲端服務。本機功能不需要 API Key；你可以在 AI 設定刪除下載的模型。需要相容的 64 位元裝置及足夠的儲存空間與記憶體。

OpenRouter 雲端模型
輸入 OpenRouter API Key 後，金鑰會以 Android Keystore 保護並保存在手機。只有你同意資料傳送並按下分析，才會將目前網域、有限的元件結構、已儲存的自訂 CSS／JS／HTML 與元件規則，以及你輸入的問題傳送給 OpenRouter 與所選模型供應商，用於檢查天眼規則。應用不主動擷取文章內文、表單值、Cookie 或網址參數；但問題、元件命名、規則與自訂程式碼可能含有你或網站填入的個人資料；編輯過的 HTML 也可能包含元件原有文字，請先確認內容。API Key 用於向 OpenRouter 驗證身分，不提供給網頁。應用向 OpenRouter 指定 data_collection=deny，排除允許收集資料的模型供應路徑。OpenRouter 本身的帳戶記錄、費用及其他資料處理仍依其政策與帳戶設定。政策：https://openrouter.ai/privacy

瀏覽網站及查詢版本
開啟網頁時，該網站及其載入來源會收到網路請求、IP 位址、瀏覽器識別與適用的 Cookie。這些網站的資料處理由各自的政策規範。查詢最新 Chromium 版本會連線至 Google 的版本服務；手動更新 AI 模型清單會連線至 OpenRouter。一般網頁檔案下載由 Android 下載服務處理；長按圖片下載由應用驗證圖片後寫入系統 Downloads，書籤匯入與匯出只使用你透過系統選擇的檔案。

連線與自訂程式碼
Google 同步與 OpenRouter 的原生連線使用 HTTPS 憑證驗證。網頁瀏覽預設驗證憑證；你可以從網址列的連線圖示手動允許特定 HTTPS 主機名稱的永久例外（包含其不同連接埠，不含其他子網域）。例外會持續保存到你關閉，降低網站身分驗證保障，網址列會顯示警示。HTTP 網站本身不加密。你加入的 JavaScript 具有該網頁程式碼的能力，可能讀取頁面內容或發送請求，請只使用你了解用途的程式碼。

保存、停止與刪除
本機資料由各功能管理。瀏覽記錄最多保留最近 250 個頁面，搜尋詞最多 100 筆；網站圖示快取最多保存 30 天、256 筆及 8 MiB，網頁快取由 WebView 的容量機制管理。你可以在瀏覽記錄清除記錄，在書籤或收藏刪除項目，在網域規則刪除設定，在 AI 設定移除 API Key，或從連線圖示關閉網站憑證例外。為避免離線裝置把已刪除的收藏重新加回，收藏刪除後會保留帶有原始欄位及刪除狀態的同步紀錄；它不再顯示於收藏清單。若要移除全部本機資料（包括網站 Cookie、儲存及同步刪除紀錄），請使用 Android「設定 → 應用程式 → 澄境瀏覽器 → 儲存空間 → 清除資料」，或解除安裝；這會重設應用，請先匯出需要的書籤。

「停止同步並登出」只停止本應用同步，會保留本機及 Google Drive 中的書籤、收藏、閱讀進度與網站設定。若要刪除雲端資料，先在所有裝置停止同步，再於 Google Drive 網頁版「設定 → 管理應用程式 → 澄境瀏覽器」刪除隱藏的應用程式資料；也可在 Google 帳戶的第三方連線頁面撤銷存取權。重新連結仍有資料的裝置時，可能重新上傳所選同步的本機資料。已傳送至 OpenRouter 或模型供應商的資料，需依該服務提供的方式處理或提出刪除請求。開發者無法直接讀取或代刪你的手機、Google Drive 或個人 OpenRouter 帳戶資料。

政策變更與聯絡
資料用途若改變，會更新本說明；需要新增授權的功能會另行徵求同意。資料處理問題或刪除方式不明時，可寄信至 admin@techtarian.com；請勿提供密碼或 API Key。


無痕分頁與下載清單（1.4.0）
無痕分頁使用與一般分頁不同的 WebView Profile，不共用 Cookie、快取與網站儲存。不加入本機瀏覽或搜尋記錄，不保存分頁網址供重開復原，也不產生分頁預覽縮圖。關閉全部無痕分頁時會請求清理此 Profile 的 Cookie、網路快取及網站儲存；清理是非同步工作。若程序異常終止，下一次啟動會清理舊的無痕 Profile，且不再使用該工作階段。這不保證對作業系統或實體鑑識完全無痕，亦不隱藏你對網站、雇主或網路供應商的活動。
你主動建立的書籤、收藏、網站規則及系統下載會保留。無痕下載前會再次告知檔案及系統下載記錄的保存；系統分享、AI 分析等主動外送行為仍依原本的確認與服務政策處理。需要支援資料隔離及清理的 Android System WebView，不支援時會提示更新，不以一般分頁偽裝成無痕。
下載清單只查詢此 App 建立的系統下載記錄，不掃描手機其他 App 的檔案；已被系統移除的記錄不保證可復原。一般分頁的預覽快照可能包含目前頁面的可見內容，自 1.4.1 起保存在 App 的內部專用空間，與分頁一起保留，關閉對應分頁時刪除；重開 App 不會刪除。快照不加入 Google 同步、不放入相簿或 Downloads，並排除系統備份。無痕分頁仍不產生或保存快照。清除 App 全部資料或解除安裝會刪除這些本機快照。

首頁與每日一句
首頁按鈕開關、自訂首頁網址、是否看過初次說明，以及每日句子的起始日期僅保存在手機，不加入 Google 同步。89 句文字隨 App 離線提供，不向任何服務查詢或上傳閱讀記錄。主動點擊自訂首頁會向該網站發出一般瀏覽請求；無痕分頁仍使用獨立網站資料。清除應用程式資料會一併重設這些本機設定。

刪除瀏覽資料（1.6.0）
功能選單可選擇時間範圍，刪除本機瀏覽／搜尋記錄，或關閉該期間最後瀏覽的一般分頁並刪除其快照。時間資訊只存於手機，不加入 Google 同步。舊版未記錄時間的資料只在「不限時間」刪除。Cookie、快取和網站資料另行勾選全部清除，預設不勾選，且不受所選時間範圍限制；這可能登出網站。此操作保留書籤、收藏、下載檔案、天眼設定及無痕工作階段；無痕資料仍以關閉無痕分頁的方式清除。

開啟其他 App（1.7.0）
在網頁中主動點擊外部 App 連結，或 Android 已指定交由 App 處理的一般網址，澄境會將連結交給對應 App。對方 App 可能依其政策保存連結及使用記錄；澄境不提供瀏覽 Cookie、歷史記錄或 API Key。無痕模式離開前會提示，因為對方 App 不受澄境的無痕清理控制。澄境只查詢 HTTP/HTTPS 連結的處理程式，不保存或上傳已安裝 App 清單。未安裝對應 App 時，若連結包含有效網頁備援，會在原分頁開啟該網址。

圖片操作（1.8.0）
長按圖片可預覽、複製、下載、分享或在新分頁開啟。圖片取得請求會使用該分頁的 Cookie 及瀏覽器識別；圖片暫存在本機，單張最多 32 MiB，一般快取最多 128 MiB、無痕最多 64 MiB，在啟動及寫入時清除超過 24 小時的檔案。清除 Cookie、快取和網站資料時也清除一般圖片快取。系統可能更早回收快取；下載至 Downloads 的檔案由你保留或刪除。新的圖片下載記錄最多 500 筆，不加入 Google 同步。複製與分享透過限於該圖片的暫時讀取權限提供真正檔案，接收 App 可能依自身政策保留副本。無痕預覽在關閉全部無痕分頁時清除；無痕複製、下載或分享會事先提示可能保留在外部。data:／blob: 的暫存圖片分頁不保存供重開還原，畫面會提示先下載。
