# 尋找頁面文字：保留目前網頁的內嵌搜尋列

本次以 main 085c364（1.10.0 原始碼）為基礎，修正「尋找頁面文字」原本使用全螢幕 BrowserPanel 遮住 WebView 的問題。沒有回退至舊版本。

點選三點選單的原入口後，關閉全螢幕選單，於主視窗網頁區上方顯示小型輸入列。原 WebView 不被更換，不重新載入、不開啟另一個分頁。搜尋列只在尋找時出現，其他工具列外觀與位置不變。

輸入時使用原生 findAllAsync / FindListener，顯示目前筆數／總筆數，頁面原生反白；上一筆／下一筆呼叫 findNext，捲動至符合文字並支援循環。空查詢取消原生搜尋並移除反白；無結果顯示 0/0 並停用箭頭。執行緒與事件都沿用 UI 執行緒，不讀取網頁正文傳送到外部服務。

關閉／返回會清理反白與 listener，保留目前網頁。切換、關閉分頁、文件重新載入與 Activity 銷毀時清理所屬搜尋；過期回呼不能修改新查詢或新分頁狀態。查詢只在記憶體，不加入搜尋引擎歷史、分頁復原、偏好設定或 Google 同步。無痕仍使用同一個隔離 WebView，不跨入一般分頁。

標準寬度是一條小型搜尋列，保留 48 dp 的上／下／關閉觸控區。極窄畫面或大字體改成輸入及操作兩列，不將按鈕擠出畫面；保留深淺色與網址列在上／在下設定。鍵盤出現時網頁隨可用高度縮排；按箭頭或鍵盤搜尋鍵隱藏鍵盤，留出更多網頁空間。

驗證加入 8 項 session JVM 測試、9 項 Android WebView／介面案例，以及一項真正 R8 混淆 APK 的黑箱操作。保留原有全部回歸與跨程序測試。測試涵蓋實際 3 筆搜尋、捲动、循環、0 筆、清空、快速輸入、退出／返回、分頁與重載、無痕、深色下方網址列及 320 dp／兩倍字體；實際結果以對應提交的 Actions 為準。

本次使用者要求修正並推送 main；沒有調整版本號、發布新 Release、移動既有 Tag 或讀取簽章 Secrets。既有已發布 APK/AAB 不會隨原始碼更新自動改變。
