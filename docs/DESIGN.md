# 澄境瀏覽器：Android 設計

Design Read:
artifact: Android 原生瀏覽器
audience: 想排除干擾廣告的一般成年使用者
purpose: 正常瀏覽；看見結構、預覽移除、按網域儲存與復原
visual-language: 澄境暖紙與墨綠；原生工具列與清楚層級
mode: extension
visual-variance: 3
motion-intensity: 2
information-density: 5
asset-dependence: 1
brand-fidelity: 9

palette: 沿用澄境 #f1eee7、#fbfaf6、#1d2925、#147a64；深色 #0f1513、#1a2420、#f2efe7、#69dfc0。
typography: Android 系統字體；展示 36、頁標 24、區標 18、正文 15–16、輔助 12–13 sp。正文行距至少 1.45。
spacing: 4 dp 基準；8、12、16、24、32 dp。
shape: 工具觸控面至少 48 dp；網址列視覺高度 44 dp、22 dp 圓角；面板 24 dp 圓角。
depth: 背景色與留白建立層級；只在面板使用原生浮層。
motion: 原生面板與進度條；尊重系統動畫縮放。
asset plan: Material 向量圖示；澄境家族的墨綠底／翡翠環線／暖白指南針品牌符號，不借用 Chrome 標誌。

天眼採「瀏覽 → 看見邊界 → 點選 → 調整父層 → 預覽移除 → 儲存網域規則」。例外是本次開啟期間的網域暫停，不刪掉既存規則。自訂 CSS / JavaScript 由使用者明確儲存；AI 只提出有界的結構規則。

0.1.2：底部天眼直接進入選取，設定移至選單。選取的點擊由原生瀏覽器接管，頁面與 iframe 不收到觸控事件；捲動保留。分頁數字以實際筆畫邊界置中，網址列的上下留白對稱。

0.1.3：根據實體手機截圖修正單一「1」的視覺重心；原本外框幾何置中的證據不足以證明這個字形看起來置中。匯入 Chrome 書籤入口直接出現在主選單。


0.1.5：書籤與收藏使用全螢幕資料庫畫面，系統列跟隨主題。書籤根層僅顯示資料夾，無資料夾的書籤收在「未分類」，搜尋時跨資料夾展開匹配結果。大量內容使用延遲列表。收藏為獨立頁籤，保留章節與本頁進度；首頁的「繼續閱讀」只列最近三筆收藏。

網址列可在上方或下方；天眼與導覽工具列放在另一端。攔截事件只用選單上的 5 dp 小點提示，詳細紀錄由使用者主動開啟。刷新使用翡翠色原生下拉指示器，從頁面頂端開始拉動才觸發，天眼選取不啟用此手勢。


0.1.6：依實體手機截圖修正自適應 App 圖示貼邊問題。Android 將 108 單位圖層的中央區域套用系統遮罩，原本約 66 單位寬的前景因此幾乎填滿可見範圍。前景圓環與指南針以 (54,54) 為中心等比例縮至 78%，背景不縮放；以系統實際繪製的圖示確認留白。首頁使用的獨立品牌圖原本已有留白，不在這次修改範圍。


0.1.7：天眼右側的高頻操作位置改為「快速收藏」，使用空心／實心星號表示目前分頁是否連結收藏；再次點擊更新進度。例外切換移至主選單，例外中的狀態列仍保留恢復入口。Chrome 書籤匯入僅位於書籤頁右上角，主選單保留「書籤」入口。


0.1.8：0.1.7 的實體手機截圖仍顯得圖案太滿，撤回前版留白已足夠的視覺結論。自適應前景改為原始圖形的 60%，系統中央遮罩中圖案直徑約占 55%；獨立品牌圖與相容版本以 90% 前景縮放維持近似比例。最近工作項目明確使用 App 圖示資源，並驗看系統最近使用畫面。

快速收藏使用空心 StarOutline／實心 Filled.Star，狀態取決於目前網址在收藏中是否存在，而不是分頁有無連結收藏 ID；保存進度的行為維持。主選單不放拖曳橫槓，標題前保留系統頂端區域及 16 dp 內距；其他面板維持既有拖曳提示。


0.1.9：依使用者長標題與選單間距的實機截圖重做主選單及設定。參考澄境筆記設定的分類導覽、分組表面與選擇卡，使用一致的 64 dp 操作列、單行輔助文字、四等寬快捷入口。主選單／設定採固定外框；其他內容面板限制在相同最大高度，所有頁面寬度、左右留白及返回／關閉統一。詳見 `MENU-DESIGN-019.md`。


0.1.10：使用者指出 0.1.9 的浮動面板仍有不上不下、不寬不窄的感覺，撤回該外框尺寸的設計結論。統一改成真正全螢幕頁面；背景鋪滿四邊，內容在系統安全區內排版，保留已整理的分組與列高，不再露出底下的網站或工具列。


0.1.11：依 Chrome 參考圖，在網址列膠囊與分頁按鈕之間加入獨立「＋」。沿用 48 dp 觸控範圍、24 dp Material 向量圖示，與相鄰控制項共用中心線；網址列維持 44 dp 視覺高度，提示文字限制為單行，上下配置一致。


0.1.12：使用者回報下方 R 角遮住網址列與分頁工具。共同外框的左右內距由 8 dp 改為 24 dp，三個元件作為同一排內縮；保留 44 dp 網址列高度、48 dp 按鈕觸控範圍與既有中心線。


0.1.13：在書籤編輯視窗的名稱與資料夾之間新增網址欄位，沿用相同寬度及外框樣式，預填完整網址，使用網址鍵盤；錯誤提示顯示在欄位下方。文字區可捲動，以容納鍵盤開啟後的三個欄位。收藏重新命名仍只編輯名稱。


0.1.14：依使用者已熟悉天眼的回饋，移除首頁「先試一次天眼」卡片及其後 26 dp 間距，簡介與快速前往之間保留單一 32 dp 間距。其他首頁內容自然上移。
