# 天眼選不到的元件，怎麼處理？

先判斷它的來源；看得到的畫面，不一定都有一個可以單獨刪除的網頁元件。

- **內嵌頁面或封裝的元件**：先用「選取外面一層」，或從「結構清單」找外框。跨網域 iframe 可以整塊移除；封閉 Shadow DOM 的內部節點不會以一般方式開放，但外層容器仍可能選得到。
- **裝飾圖層、偽元素或背景圖片**：通常要處理承載它的元素或樣式，不能只把那個圖案當成另一個 DOM 節點。可以選外層、再用自訂 CSS 精確調整。
- **圖片、Canvas 或影片裡的內容**：若廣告已畫在同一張圖或同一段影像裡，不能靠 DOM 單獨刪除它。整塊隱藏會連正常內容一起隱藏；局部遮罩是視覺遮擋，版面移動後可能失準。
- **自動跳轉或新視窗**：使用網域的「防止跳轉與彈窗」。這是瀏覽行為，不是頁面裡的可見元素。
- **有獨立廣告來源、但不易選取的內容**：後續可以加入「資源請求攔截」，在下載廣告資源前處理；需精確辨識網址並提供例外，避免把文章或播放器一起擋掉。0.1.9 尚未新增一般資源攔截或局部視覺遮罩。

AI 能協助判斷外層結構與現有移除規則；它不能把同一張圖片中的某個圖案變成獨立 DOM，也不能保證每種網站都能自動處理。沒有具體網站結構時，以上是分類方法，並非對某個網站原因的判定。

參考：[MDN Canvas](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/canvas)、[封閉 Shadow DOM](https://developer.mozilla.org/en-US/docs/Web/API/ShadowRoot/mode)。
