# 圖片下載與分享（1.8.0）

## 使用方式

長按網頁圖片可「在新分頁開啟圖片」「預覽圖片」「複製圖片」「下載圖片」「分享圖片」，HTTP(S) 圖片另可複製圖片連結。帶有超連結的圖片保留連結開新分頁及複製連結；下載使用圖片的 currentSrc，不把外層 href 當成圖片。不加入 Google Lens。一般文字選取、天眼選取模式及原有五個工具列按鈕維持原本行為。

預覽使用全螢幕圖片檢視器，可雙指縮放、拖曳、雙擊放大。預覽解碼最多約 400 萬像素及 4096 像素邊長以控制記憶體，下載、複製與分享保持原始檔案，不重新壓縮。GIF／WebP 動畫依裝置解碼器播放。

HTTP(S) 圖片在正常網頁分頁開啟。data:／blob: 的來源只存在原網頁工作階段，另開暫存圖片分頁，畫面明確提示重開 App 不保留；需要保存請下載。這些分頁不污染一般分頁的還原清單。

## 正確的檔案格式

舊版先用圖片網址猜副檔名，無副檔名網址可能被命名為 .bin。新版先讀取受上限約束的內容，以 PNG、JPEG、GIF、WebP、BMP、ICO、AVIF、HEIC／HEIF 檔頭辨認格式，再經 Android ImageDecoder 驗證。裝置無法解碼的格式、HTML 錯誤頁及截斷檔案會回報失敗。副檔名和 MIME 以檔案內容為準，不盲信網址、Content-Disposition 或 Content-Type。

HTTP 請求沿用該分頁的一般／無痕 Cookie 與 User-Agent。重新導向每一站重新查詢 Cookie，不將前一主機 Cookie 轉交下一主機。Referer 僅包含來源網域，不含私人頁面路徑及參數，HTTPS 降級 HTTP 不送 Referer。保留憑證驗證，不繞過網站存取限制。data: 在本機解碼；blob: 透過原 WebView 讀取並分段取回，分頁離開或關閉後停止，不新增 JavaScript 原生介面。

Android 10 以上透過 MediaStore 的 pending 寫入，在完成前不公開半份檔案；成功後才加入下載清單。Android 9 仍只在使用者按下載時要求舊式儲存權限，並註冊到 DownloadManager。檔案放在 Downloads/ChengJing，使用獨立檔名。一般網站檔案下載仍走原有 DownloadManager。

## 複製、分享與保存期限

複製與分享使用只開放 shared-images 子目錄的 FileProvider，提供原圖片 MIME、content URI 與暫時讀取權限；不交出其他快取、資料庫、Cookie 或金鑰。分享只開啟 Android 選擇面板，由使用者決定接收 App。三點選單的「目前頁面 → 分享」仍傳遞網頁網址和標題。

每張圖片上限 32 MiB，同時最多兩個取得圖片工作。圖片操作快取在 App 啟動及寫入時，清除超過 24 小時的檔案；一般最多 128 MiB，無痕最多 64 MiB。最近複製的圖片在期限內優先保留；系統也可能先回收快取。使用者已下載到 Downloads 的檔案不套用快取期限。新的自建下載記錄最多 500 筆。清除 Cookie、快取和網站資料時也清除一般圖片操作快取，保留已下載檔案。

無痕預覽使用不對外開放的暫存目錄，關閉全部無痕分頁、正常結束或下一次啟動清除。無痕的複製、下載及分享先提示會留在 App 外，取消不匯出。剪貼簿標示敏感內容；外部副本不保證隨無痕清理消失。

## 範圍與驗證

目前支援可由 Android ImageDecoder 解碼的點陣圖片，不匯出 SVG、CSS 背景圖或 Canvas。需要完整 Referer 或特殊網頁驗證的來源仍可能拒絕下載；會明確提示失敗。未宣稱涵蓋所有圖片網站或所有接收 App。

ImageFormatTest 驗證檔頭及正確命名；ImageActionsTest 使用本機 HTTP 圖片、偽造格式及不同主機的轉址，核對下載檔位元組、MIME、MediaStore 完成狀態、長按選單、預覽、data:／blob:、無痕與真實跨 App 讀取。release-smoke 的獨立接收器只讀取測試圖片的 MIME、大小與 SHA-256，不傳送至任何人。R8 測試以最佳化 APK 的實際 UI 執行圖片操作，保留既有回歸檢查。

公開 Google 圖片頁另有選用的 liveGoogleImageDownload 測試；CI 使用本機合成內容，避免公開頁改動阻擋每次發布。實際測試結果以該版本驗證記錄及對應 Actions 為準。

### 2026-09-22 本機驗證

Android 16 模擬器（隔離的 .qa 套件）已完成 8 項圖片回歸情境；一般操作及刪除資料的 15 項相關回歸亦完成。107 項 JVM 測試與 debug／release lint 通過。正式最佳化設定的 APK 已透過獨立測試 App 驗證預覽雙擊後畫面確實放大、圖片下載清單、複製與系統分享；接收端的 MIME、檔案大小及 SHA-256 與原圖一致。未宣稱在使用者實體手機驗收。

使用者提供的 Google「伊莫」圖片搜尋原頁，在 QA WebView 長按下載測試通過。實際取得 Google Play 白色角色圖片，存成 52,062 bytes、240 × 240 的 WebP；已從模擬器 Downloads 拉回並開啟檢視，確認圖片內容，不是 .bin 或錯誤網頁。公開頁檢查屬當日結果，搜尋頁及 CDN 之後可能變動。
