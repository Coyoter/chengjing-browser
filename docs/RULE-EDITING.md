# 既有天眼規則的編輯與 AI 修訂（1.9.0）

Design Read: Android 既有設定的延伸，服務需要反覆微調網站的日常使用者。沿用澄境暖白／墨綠、玉綠重點色與 18dp 群組圓角；密度 5/10、品牌一致性 10/10，無外部素材或額外動畫。標題 20sp、內文 13sp、輔助說明 12sp；程式碼沿用等寬 12sp／18sp 行高。AI 入口置於編輯內容上方，儲存放在內容下方，刪除獨立標示且需確認。

- 「已儲存的網站修改」依網站程式碼、自訂元件、隱藏元件分組。點自訂項目開啟原內容，儲存以同一 ID、同一順序更新；其他規則保留。
- 「所有網域規則」點選網域可進入編輯列表；若不是目前網站，會在新分頁開啟該網域，供後續讀取頁面來源。未儲存的編輯可帶入 AI，返回編輯頁仍保留。
- AI 修訂以獨立回覆格式限制在目前一項規則。模型不能更改 selector、ID、其他元件、跳轉防護或其他網站設定。遺漏欄位保留，空字串清空該欄位。回覆先預覽，按「更新原規則並套用」才儲存，仍可使用上一版復原。
- 每次分析會從目前 WebView 重新讀取同一文件的原始 HTML 快照。快照在此頁載入、套用天眼程式碼前擷取，包含清理後的頁面文字；不是重新 HTTP 抓取、完整原始回應或全站巡覽，也不保證涵蓋稍後的動態變化。
- HTML 排除表單控制內容、可編輯區、script、事件屬性、任意 data 屬性、瀏覽器生成節點與 URL 屬性的查詢參數。網站快照最多 24,000 字元，元件快照合計上限 240,000 字元，只在該 WebView 記憶體保存，不寫入磁碟或同步。雲端最多使用 24,000 字元，本機最多 6,000 字元，截取會標記。
- 雲端分析需本次資料同意，明示 HTML 可能包含私人頁面文字；Gemma 在本機執行。原始 HTML 與舊程式碼一律視為資料，不能覆蓋使用者要求。當切換分頁、導覽、重載或原設定被其他流程更新，舊提案不能套用。

驗證：`RuleRevisionTest` 檢查原位替換、欄位保留、越界拒絕、來源與需求、長度限制；`RuleEditingJourneyTest` 操作實際編輯頁並檢查 WebView 結果、重建後保存、刪除確認、來源清理、AI 套用前不儲存及文件過期拒絕。AI 測試以確定的回覆替代外部模型，不代表測過所有模型的回答品質。
