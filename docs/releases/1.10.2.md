# 澄境瀏覽器 1.10.2

## 分頁選單細節修正

- 縮小分頁一覽右上角三點選單的「關閉所有分頁」背景，移除原本強制 188 dp 最小寬度與多餘的有色上下留白。標準字體下改為約 144 × 48 dp 的單一操作區。
- 文字在可見背景內水平與垂直置中，左右留白對稱，修正中文字型額外行距造成的視覺偏移。系統字體放大時容器可隨內容調整，不裁掉文字，保留至少 48 dp 高的觸控範圍。
- 三點選單位置、底部滿寬「新增分頁」、分頁卡片、第一層天眼工具列、頁內搜尋與快照功能不重新設計。
- 保留原生選單的返回／點外側收起、空分頁集停用狀態與關閉確認。只關閉目前選取的一般或無痕分頁集，不影響另一組及已儲存的下載、書籤、收藏。

## 版本與驗證

versionName：1.10.2；versionCode：35。沿用原始 APK／AAB 簽章及 R8 混淆。新增實際可見背景與文字的中心、尺寸、觸控區、深淺色、320 dp 容器與兩倍字體檢查；所有既有回歸仍保留。測試、建置及發布的實際結果以對應 GitHub Actions 與 BUILD.json 為準。
