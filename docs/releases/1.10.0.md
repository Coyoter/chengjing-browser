# 澄境瀏覽器 1.10.0

- 新增網頁暫存檔案（blob）與內嵌資料（data）下載，涵蓋網站產生的影片、音訊、PDF、文字、壓縮檔等檔案。
- 修正播放器右下角選單下載暫存影片時，顯示「此類型的下載尚未支援」的問題。
- 暫存檔案採分段儲存，Blob 上限 2 GB，不套用圖片工具的 32 MB 限制。已驗證超過 132 MiB 的 MP4，儲存後檔案內容一致且影片資訊正常。
- 下載清單顯示進度、影片／音訊圖示與取消操作。取消或來源頁面關閉、重新載入時，移除未完成檔案；應用中斷後重開會清理暫存輸出。
- 依 MIME 與常見檔頭改善檔名副檔名，完成檔案可交給其他 App 開啟。一般 HTTP／HTTPS 下載仍交由 Android 系統下載服務處理。
- 無痕下載保留單次明確確認；匯出檔案與下載紀錄不隨無痕分頁清除，暫存檔案的下載紀錄不保存無痕來源網址。

網頁暫存下載完成前，請保留來源分頁，不要重新整理。分段串流、DRM 受保護影片及已失效的暫存連結，仍須使用網站提供的下載方式。

versionName 1.10.0；versionCode 33。沿用原正式簽章。
