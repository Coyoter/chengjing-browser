# 澄境瀏覽器 1.10.1

## 尋找頁面文字

- 修正開啟「尋找頁面文字」後全螢幕選單遮住原網頁的問題。現在回到目前頁面，在上方顯示搜尋列，網頁保持可見並可捲動。
- 輸入文字即使用 WebView 原生搜尋及反白，顯示目前位置／符合總數；支援上一筆、下一筆與循環移動。沒有結果時顯示「找不到」並停用箭頭。
- 關閉搜尋後清除反白，恢復原本網址列與工具列；切換分頁、關閉頁面或重新導航時清理搜尋狀態，不影響其他頁面。
- 搜尋詞僅保存在當次記憶體，不加入歷史、Google 同步或一般偏好設定。無痕沿用原本獨立的 WebView。
- 搜尋列支援深淺色、上下網址列設定、窄螢幕及較大字體，維持可操作的輸入區與按鈕。

第一層天眼工具列、首頁、分頁卡片、快照保存、圖片與檔案下載的既有修正全部保留；沒有重新設計一般瀏覽畫面。

## 套件與驗證

versionName：1.10.1；versionCode：34；Android 9 以上。沿用原本的正式簽章與 R8 混淆、最佳化、資源縮減。

由正式發布流程重新執行一般測試、頁內搜尋操作測試、跨程序檢查，以及獨立測試程式操作真正混淆 APK；之後建置 APK／AAB，驗證簽章、套件版本與附件雜湊。實際結果以對應 GitHub Actions 及 BUILD.json 為準。

APK 用於相同簽章的安裝更新，AAB 用於 Google Play Console 上傳。本次 GitHub Release 不代表已提交或通過 Google Play；隔離模擬器不替代使用者實體手機與真實 Google Drive 双裝置驗收。附件另含同一提交的原始碼、R8 對照資料、建置紀錄與 SHA-256 校驗清單，舊版本不覆蓋。
