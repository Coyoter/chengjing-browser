# 澄境瀏覽器 1.6.0

- 功能選單重複的「歷史記錄」改成「刪除瀏覽資料」；上方入口與清單標題統一為「瀏覽記錄」。
- 新增六種時間範圍，可勾選刪除瀏覽／搜尋記錄及關閉該期間最後瀏覽的一般分頁，同步清除被關閉分頁的快照。
- Cookie、快取和網站資料可另外勾選全部清除，預設不勾選，畫面明確標示「不限時間」及可能登出網站。Android WebView 不支援像 Chrome 一樣按時間精準清除這類資料；舊版沒有時間的記錄／分頁也僅於「不限時間」刪除。
- 修正網站圖示快取可能持續累積：最多保存 30 天、256 筆及 8 MiB，先淘汰最舊檔案。WebView 網頁快取保留引擎既有容量管理。
- 保留書籤、收藏、下載、天眼設定與無痕工作階段；App 重啟不會把舊分頁重新算成剛瀏覽。
