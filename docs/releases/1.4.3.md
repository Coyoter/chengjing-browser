# 澄境瀏覽器 1.4.3

## 分頁一覽操作調整

底部恢復只有滿寬的「新增分頁」按鈕；在無痕分頁集顯示「新增無痕分頁」。關閉所有分頁移到分頁一覽右上角的三點選單，點開後才出現，不再與新增按鈕並排。

保留左上角返回、一般／無痕切換與原有卡片設計。整批關閉仍先確認範圍與數量，只處理目前選取的分頁集；取消、返回或關閉選單不會刪除分頁。空的分頁集不允許執行整批關閉。

第一層天眼工具列、瀏覽器三點主選單的分享位置、快照保存、無痕隔離與同步邏輯都不改動。已關閉分頁的快照與復原紀錄照原規則清理，另一組及歷史、下載、書籤、收藏不受影響。
