# 澄境瀏覽器 1.11.0

- 修正 Google 同步遇到暫時逾時便停止、直接顯示 Java 例外的問題。讀取與更新請求加入有限次漸進重試，區分網路等待、Google 限流與需要重新授權的情況。
- 同步尚未完成時保留本機資料與上次成功時間；重新同步會清除過時提示。短時間切回 App 不重複跑完整同步，沒有變更的雲端快照不重複上傳。
- 新增網站定位：網站提出請求後，先確認網站授權，再確認 Android 定位權限，支援系統提供的概略／精確位置。未允許時不提供座標。
- 網址列「網站資訊」新增網站定位的詢問、允許、封鎖選項，以及手機定位權限與定位服務設定入口。撤回授權後重新載入相關頁面，停止先前的定位請求。
- 一般網站授權保存在本機；無痕授權獨立且不寫入磁碟，關閉全部無痕分頁即清除。定位授權與座標不加入 Google 同步。
- 新增慢速回應、限流、授權失效、取消、帳戶隔離、定位授權與實際網頁座標回傳的回歸測試。

versionName 1.11.0；versionCode 36。沿用原正式簽章。
