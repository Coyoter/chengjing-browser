# 澄境瀏覽器 1.5.0

## 首頁設定

設定 → 瀏覽 → 首頁設定新增「顯示首頁按鈕」，預設關閉；關閉時不顯示網址設定或首頁按鈕，也不改原工具列排列。開啟後按鈕位於網址列前方，可選澄境首頁或自訂 HTTP/HTTPS 網址。自訂網址先驗證再儲存，不把錯誤網址變成搜尋；關閉開關保留已儲存選擇，下次開啟可繼續使用。

首頁按鈕在目前分頁開啟目標，不新增分頁、不取代新分頁或重啟後的工作階段還原，無痕分頁不會切換成一般分頁。內建首頁亦保留前後頁導覽。

## 每日一句

新使用者第一次看澄境首頁仍有原本說明，之後改成作者提供的全部 89 句，保留文字與順序。以首次顯示句子的當地日期為起點，每天一則，同天多次開啟不跳句，完整輪過後從第一句開始；未開 App 的日子仍隨日期推進。跨午夜、回到前景、調整時區會更新日期，不用網路或外部服務。

長句隨可用寬度適度缩小字級；不截斷句子、不加刪節號，極大系統字體時以自然增高與捲動保留完整文字。深淺色、首頁快速入口與最近收藏繼續保留。既有使用者有工作階段或历史記錄時升級直接進入每日一句，不重播說明。無痕首頁保留其必要隱私說明。
