# 澄境瀏覽器 1.13.0

- 加入使用者可開啟的 APK 安裝來源授權；下載清單開啟 APK 時交由 Android 顯示安裝確認。
- 設定／瀏覽加入「密碼與自動填入」，顯示並開啟系統密碼服務選擇；一般分頁支援 Android Autofill，無痕維持停用。密碼保存及跨裝置同步由所選服務負責。
- 有 GMS 與支援瀏覽器時，提供 Google 登入協助：可在系統瀏覽器重新開啟原網站並利用該瀏覽器已有的 Google 登入狀態。登入在系統瀏覽器完成，原澄境分頁保留；沒有 GMS 時維持原有網頁流程。
- 新介面文字提供既有的 17 種語言，沿用深淺色的澄境設計。

供應商相容性有邊界：Samsung Pass 官方限制網站填入於 Samsung Internet；小米及 Google 的真實服務仍須在對應手機確認。GMS 原生帳號授權不能直接替任意網站建立澄境 WebView 的登入 Cookie。本版不建立獨立密碼庫。

驗證使用隔離 Android 測試裝置，包含系統安裝確認、實際 Autofill 填入、無痕排除、Google 網址邊界與既有功能回歸；尚未完成小米／三星實機及真實 Google 帳號確認。

versionName 1.13.0；versionCode 42。沿用原正式簽章。Google Play 後續提交前須完成 APK 安裝權限申報；本次發布為 GitHub Release。
