# 澄境瀏覽器 1.7.0

- 網頁中主動點擊 App 專用連結或 `intent://`，可開啟已安裝的對應 App。
- YouTube 等一般網站連結，依 Android 的「開啟支援的連結」設定交給對應 App；普通網頁繼續留在澄境。
- 沒有對應 App 時，使用連結提供的網頁備援；沒有備援則提示並保留頁面。
- 保留自動跳轉、子框架及天眼選取時的攔截。無痕分頁離開到其他 App 前會提示。
- 點擊開新視窗的 App 連結，不留下額外的空白分頁。
