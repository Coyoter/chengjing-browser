# 澄境瀏覽器 1.8.0

- 修正 Google 圖片等無副檔名網址被存成 `.bin`：讀取實際圖片內容，再決定 PNG、JPEG、WebP 等格式與檔名；保留原始圖片位元組，不轉檔降低品質。
- 長按圖片新增「在新分頁開啟圖片」「預覽圖片」「複製圖片」「分享圖片」，保留「下載圖片」及連結操作，不加入 Google Lens。
- 預覽支援雙指縮放、拖曳與雙擊放大；複製與分享傳遞可供其他 App 讀取的圖片檔案。
- 支援網頁內的 data:／blob: 點陣圖片。這類圖片開成暫存分頁時會提示重開不保留；需要保存可下載。一般網址的圖片分頁維持原本還原方式。
- 圖片操作快取增加 24 小時清理期限及容量上限；無痕預覽在關閉全部無痕分頁時清除，匯出前會提示檔案可能留在 App 外。

versionName 1.8.0；versionCode 29。沿用原正式簽章。單張圖片上限 32 MiB；網站拒絕存取或不支援的內容會顯示失敗，不再把錯誤網頁存成圖片。

驗證包含錯誤 Content-Type／副檔名、重新導向、data:／blob:、真正的系統下載檔案與跨 App 圖片讀取，以及未插入測試保留規則的 R8 安裝包。公開頁與本機裝置結果見圖片操作文件；每次發布仍以對應 Actions 的實際結果為準。
