# 澄境瀏覽器 1.14.0

- 移除網站權限一律拒絕及相機／麥克風不支援的誤導提示。相機、麥克風分別取得網站與 Android 授權；受保護影音與 MIDI 使用各自的權限處理。
- 網站資訊可調整各項權限，也可只為目前網站允許第三方 Cookie，方便處理需要它的登入或嵌入內容。無痕授權與一般分頁分開，不永久保存。
- 檔案上傳可選已有檔案，或開啟相機拍照／錄影、錄音工具；支援網站指定的拍攝上傳。
- 使用者主動點擊的開新視窗連結可在澄境開啟；非主動彈窗仍攔截。
- 移除 20 個分頁上限。重開應用時先保留分頁與縮圖，只有可見分頁立即載入，其餘切換後載入。
- 修正分頁切換與網頁載入後的無障礙文字樹刷新，讓讀屏工具取得目前文件。
- 更新 17 種語言及隱私權政策，保留既有定位、密碼填入、下載、APK 安裝及天眼功能。

實測包含相機與麥克風串流、錄製影音、系統相機回傳完整照片、授權拒絕與撤回、無痕隔離、主動／非主動新視窗、Cookie 例外及 25 個分頁還原。發布流程另執行完整既有回歸與正式 R8 最佳化版本檢查。

這次修正不代表已完成所有 Chrome 功能。網頁通知／Push、網頁螢幕分享、Web Bluetooth／WebUSB、通行金鑰、Chrome 擴充功能與完整 PWA 仍有限制，詳見[功能與核心限制清單](https://github.com/Coyoter/chengjing-browser/blob/main/docs/BROWSER-COMPATIBILITY.md)。特定網站登入與付費影音仍受服務商政策、裝置及核心版本影響。
