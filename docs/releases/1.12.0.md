# 澄境瀏覽器 1.12.0

- 新增繁體中文、簡體中文、英文、日文、韓文、法文、德文、西班牙文、葡萄牙文、阿拉伯文、泰文、俄文、印地文、印尼文、越南文、孟加拉文及烏爾都文，共 17 種介面語言。
- 設定／外觀新增語言下拉選單，使用各語言原名方便辨識，選取項目有標記。選單使用與卡片不同的底色、圓角、細邊框和陰影，深淺色外觀都有清楚層次。
- 首次啟動預設跟隨手機語言，沒有支援的對應語言時使用英文；可手動選擇並記住偏好。Android 支援時也可使用系統的應用程式語言設定。
- 介面、提示、狀態、首頁語錄、內建練習頁與應用內隱私政策一併提供多語系；所有語言隨安裝檔提供，切換不需要下載語言包。
- 阿拉伯文及烏爾都文採右至左排列；網址、程式碼維持正常閱讀方向。切換語言保留正在開啟的分頁、網頁與未儲存的天眼預覽，不翻譯網站內容或使用者儲存的文字。

「印度文」以印地文（Hindi）實作。語言偏好只儲存在本機，不透過 Google 同步覆蓋另一台裝置的選擇。

驗證涵蓋資源完整性、語言對應、隔離 Android 模擬器的 17 語言選取與保存、首次啟動、深淺色介面，以及 R8 最佳化版的語言切換與重啟。翻譯未經各語言母語者逐項審校，尚未完成小米實機確認。
