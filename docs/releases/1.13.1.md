# 澄境瀏覽器 1.13.1

- 移除 Google 網站登入時「改用其他瀏覽器開啟」的詢問與跳轉，登入網址沿用澄境內既有網頁流程。
- 移除設定／瀏覽中的「Google 登入協助」開關，以及 17 種語言的相關提示文字。
- 即使舊版曾開啟登入協助，也不會再觸發外部瀏覽器提示。

這次修正移除外部瀏覽器登入協助，不代表已實作通用的原生 Google 網站登入。網站是否接受澄境內登入仍取決於網站本身。澄境自己的 Google Drive 授權、系統密碼自動填入及 APK 安裝功能維持原有流程。

versionName 1.13.1；versionCode 43。沿用原正式簽章。本次發布為 GitHub Release。
