# 澄境瀏覽器 1.4.1

## 分頁快照修正

一般分頁的快照現在會與分頁一起保存在手機內部。關閉或重開 App 後，分頁一覽會讀回上次的快照，不必逐一切換或等待網站重新載入。重新載入、暫時離線與網路錯誤不再清空最後成功的快照；只有關閉對應分頁，才移除該分頁的快照。

每個一般分頁使用固定且獨立的識別碼，同網址的不同分頁也不會混用圖片。升級保留原有分頁順序、收藏關聯與網址。舊版從未寫入磁碟的快照無法憑空還原；升級後在頁面載入並顯示時取得的快照才會持續保留。

無痕分頁仍不建立或保存快照，不加入分頁復原。快照只保存在此 App 的內部空間，不加入 Google 同步、相簿或系統備份。第一層天眼工具列、三點選單分享與分頁卡片外觀均不改動。

## 版本與驗證

versionName 1.4.1；versionCode 22；沿用原始 APK/AAB 簽章。正式建置及發布結果以對應 GitHub Actions 和 BUILD.json 為準。回歸檢查包含 Activity 重建、真正停止 App 程序後再啟動、重開後只刪除已關閉分頁的快照，以及無痕不落地。

APK 供相同簽章的安裝更新，AAB 供 Google Play Console 上傳。此次 GitHub Release 不代表代為提交 Google Play；使用者實體手機與真實 Google Drive 雙裝置驗收的既有範圍不變。舊版 Release 附件不覆蓋。
