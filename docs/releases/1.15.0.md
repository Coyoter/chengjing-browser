# 澄境瀏覽器 1.15.0

新增「安裝為網頁應用程式」功能，可將任何目前瀏覽的頁面像應用程式一樣釘選到手機主畫面，並於獨立視窗中順暢使用。

- **三種開啟模式自由選擇**：
  - **獨立應用程式**：隱藏瀏覽器工具列，以獨立多工視窗卡片開啟，並自動套用您的天眼自訂樣式與規則；若離開原網域或遇到憑證警示，頂部會自動顯示安全列與回首頁入口。
  - **精簡視窗**：保留獨立視窗卡片與極簡頂部控制列，方便隨時重新整理、複製網址或回到澄境編輯。
  - **瀏覽器捷徑**：在主畫面建立捷徑，點擊後直接以澄境分頁開啟該頁面。
- **自動擷取名稱與高清圖示**：自動讀取網頁 Manifest 與圖示資源，產生符合 Android 自適應圖示規格的桌面圖示，並支援自由命名。
- **網頁應用程式管理**：從主選單的「網頁應用程式」集中管理已安裝項目，可隨時重新釘選到主畫面、編輯名稱與模式、在澄境分頁開啟或移除。

版本：1.15.0（versionCode 47）。
