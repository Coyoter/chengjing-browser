# 澄境瀏覽器 1.9.0

- 設定 → 瀏覽新增「預設搜尋引擎」，Google 維持預設，可切換 Bing、Yahoo、百度、Naver 與 Wiki。
- 新增自訂搜尋引擎：輸入包含一次 `{query}` 的 HTTPS 網址範本，畫面會即時檢查並顯示搜尋預覽，確認後才儲存。
- 網址列仍先判斷網址；只有一般搜尋文字會交給選定服務。搜尋文字會安全編碼，固定參數保留。
- 一般搜尋仍最多在本機保留最近 100 筆供網址列建議；無痕搜尋不加入本機記錄。搜尋引擎選擇及自訂範本只存於這支手機，不加入 Google 同步。
- 深淺色、設定重開、網址直開、搜尋記錄與無痕行為均加入回歸測試。
- 搜尋引擎選擇採用精簡雙欄卡片，支援深淺色與清楚的目前選擇；自訂內容成功儲存後才切換。
- 天眼的既有自訂規則改為點選編輯，保留先前 CSS／JavaScript／HTML；刪除是獨立操作，並先顯示確認。
- 新增「請 AI 修改這項規則」：結合本次頁面載入時的原始 HTML、目前規則與新要求，先顯示建議，再由使用者確認更新原規則。保留其他修改，並防止過期提案覆蓋新設定。
- AI 原始 HTML 採有限、經清理的記憶體快照；雲端分析前明示傳送內容及同意，本機 Gemma 仍可離線分析。
