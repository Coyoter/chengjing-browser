# 澄境瀏覽器 1.4.0

## 瀏覽工具與分頁

三點選單加入下載、歷史記錄及新增無痕分頁入口。下載清單顯示此 App 的系統下載狀態、檔案大小與開啟入口；歷史記錄支援搜尋、單筆移除及確認後清除。

分頁管理改為「一般／無痕」兩組，使用自適應卡片、網站標題、目前分頁標示與清楚的關閉按鈕。一般分頁預覽僅放在記憶體，無痕分頁不產生縮圖。第一層天眼工具列保持 1.3.1 設計，分享仍在三點選單內。

## 無痕的範圍

無痕與一般分頁使用不同的 Cookie、快取及網站儲存。不加入瀏覽／搜尋記錄、不復原無痕分頁。全部關閉後請求清理網站資料；異常終止則於下次啟動清理，不保證對作業系統或實體鑑識完全無痕。需支援 MULTI_PROFILE 與 DELETE_BROWSING_DATA 的 Android System WebView；不支援時會要求更新，不會以一般分頁偽裝無痕。

無痕不是匿名服務。主動下載、書籤、收藏與網站規則仍會保存；下載前會提醒。分享與 AI 請求仍依使用者選擇傳送相關服務。
