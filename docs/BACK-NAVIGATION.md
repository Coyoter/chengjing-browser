# 返回行為（1.11.4）

返回到瀏覽起點後，關閉目前網頁分頁並顯示新增分頁的初始頁；在該初始頁再次系統返回，讓 Android 顯示桌面或前一個應用。

1. 網站提示、圖片預覽、全螢幕、選單與天眼選取仍先關閉自己的介面。
2. 有較早網頁時照常返回；內建首頁（空網址／about:blank）仍跳過，HTTP／HTTPS 網頁及網址片段歷史仍保留。
3. 沒有較早網頁時，系統返回與工具列「上一頁」都關閉目前網頁分頁，顯示同模式的新增分頁初始頁。一般、外部連結與無痕網頁採相同規則，無痕保持無痕。
4. 其他已開啟分頁保留。若同模式已有沒有網頁歷史的初始頁就重用，否則在關閉目前頁面後建立一個；不會因分頁數已滿而無法返回初始頁。
5. 已在沒有網頁歷史的初始頁時，繼續系統返回會使用 `moveTaskToBack(true)` 離開應用；系統不允許時才 `finish()`。此步不新增或刪除分頁，正常分頁照常保存，無痕不加入儲存清單。此時工具列「上一頁」仍停用。
6. 看起來空白但仍有真實前後頁歷史的分頁，不會當成可重用的初始頁。外部連結消費及 Intent 重建去重保持相同，舊資料的來源標記仍相容。

關閉網頁沿用原有分頁清理，移除快照、停止載入並取消該頁的定位與暫存下載。一般模式的關閉與初始頁結果會儲存，無痕不加入已儲存分頁。

驗證涵蓋實際 Android Back 按鍵路徑、工具列返回、多頁歷史、重用初始頁、保留其他分頁、連續外部連結、初始頁退出及重新開啟、無痕隔離與 Activity 重建。獨立正式最佳化版測試也驗證外部 App 開啟連結後返回仍留在澄境，預設頁再次返回能顯示真正的來源 App，以及實際程序重啟後維持一個初始頁。

1.11.4 補齊 1.11.3 遺漏的「初始頁再次返回退出」步驟；網頁返回起點時仍先關閉目前頁面並顯示初始頁。
